# addHeader

応答に追加のHTTP ヘッダーを追加します。

```text
addHeader (nom, valeur)
```

## パラメーター

**nom**&#x200B;追加するヘッダーの名前。

**value**&#x200B;追加されたヘッダーの値。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [HttpServletResponse](c-httpservletresponse.md)

**次の場所で利用できます：**

* JSSP
* Web アプリ
