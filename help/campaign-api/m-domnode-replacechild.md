# replaceChild

ノードを置き換えます。

```text
replaceChild (newChild, oldChild)
```

## パラメーター

挿入する&#x200B;**newChild** ノード。

置き換える&#x200B;**oldChild** ノード。

## 戻り値

置き換えられたノード。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
