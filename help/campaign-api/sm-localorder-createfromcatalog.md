# CreateFromCatalog

パッケージからオーダーを作成します。

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## パラメーター

**catalogId** パッケージ ID。

**orgUnitId**&#x200B;のローカル エンティティ ID。 （オプション）

## 戻り値

**localOrder**&#x200B;作成した注文を返します。

## 機能

**スキーマ：** [nms:localOrder](s-nms-localorder.md)

はい
