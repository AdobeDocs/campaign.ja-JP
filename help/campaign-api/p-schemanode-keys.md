# キー

現在のノードの[SchemaKey](c-schemakey.md) キーの定義を含むテーブルを返します。

```text
keys
```

## 備考

例：

```javascript
var schema = application.getSchema("nms:delivery")
for each(var key in schema.root.keys)
  logInfo("Key: " + key.name + "\t is-internal: " + key.isInternal)
    
```

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
