# サンプル

## 静的メソッド

SOAP メソッドにアクセスするには、スキーマを表すオブジェクトでメソッドを呼び出します。 スキーマは「NLWS」グローバルオブジェクトです。 次の例では、[xtk:workflow](s-xtk-workflow.md) スキーマの[PostEvent](sm-workflow-postevent.md)静的メソッドを呼び出します。

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## 非静的メソッド

非静的SOAP メソッドを使用するには、まず、対応するスキーマの[load](f-load.md)または[create](f-create.md) メソッドを使用してエンティティを復元する必要があります。 次の例では、[xtk:queryDef](s-xtk-querydef.md) スキーマの[ExecuteQuery](sm-querydef-executequery.md) メソッドを呼び出します。

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## 制限事項

読み込まれるオブジェクト （\*\*）にデータが不足しているため、特定の非静的呼び出しを使用できません。 これは、例えば、[nms:delivery](s-nms-delivery.md)の特定の呼び出しに対してです。
