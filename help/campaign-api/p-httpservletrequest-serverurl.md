# serverURL

サーバーにアクセスするためのURLを返します。

```text
serverURL
```

## 備考

HTTPSもプロキシも使用しない場合は、空である可能性があります

## 機能

**クラスのプロパティ：** [HttpServletRequest](c-httpservletrequest.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* JSSP
* Web アプリ
