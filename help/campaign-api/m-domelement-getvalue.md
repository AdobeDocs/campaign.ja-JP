# getValue

指定されたXPathで参照されるノード値を返します。

```text
getValue (xpath)
```

## パラメーター

**xpath** パス。

## 戻り値

参照されるノードのテキスト値。

## 備考

XPathの構文は、XPath言語のサブセットのみを受け入れます。 パスの形式が正しくない場合は、例外が発生します。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
