このジョブで警告またはエラーが生成された場合のクエリ

```text
Boolean hasWarning = HasWarning ( String id )
```

## パラメーター

**id** ジョブ ID

## 戻り値

**hasWarning**&#x200B;少なくとも1つの警告またはエラーメッセージがある場合、「true」を返します
