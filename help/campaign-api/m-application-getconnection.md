# getConnection

データベースサーバーへの新しい接続を返します。

```text
getConnection ()
```

## パラメーター

なし。

## 戻り値

データベース サーバーへの[接続](c-dbengine.md)。

## 備考

[dispose](m-dbengine-dispose.md) メソッドを使用すると、スクリプトの実行終了前に接続を解放できます。

## 機能

**クラスのメソッド：** [&#x200B; アプリケーション &#x200B;](c-application.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
