# removeAttribute

属性を削除します。

```text
removeAttribute (name)
```

## パラメーター

**name**&#x200B;属性名。

## 戻り値

なし。

## 備考

要素にこの名前の属性がない場合、メソッドは効果を持ちません。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
