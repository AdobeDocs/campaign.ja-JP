# DropSelection

選択項目をナビゲーションツリーのフォルダーに移動

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## パラメーター

**スキーマ**&#x200B;選択スキーマ ID

宛先フォルダーの&#x200B;**entityFolder** ID

移動する&#x200B;**selectionList**&#x200B;の選択範囲

**folderDestId**&#x200B;宛先フォルダー

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:folder](s-xtk-folder.md)

**静的：**

はい
