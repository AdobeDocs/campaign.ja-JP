# remoteTracking

リモートトラッキング管理サービスへのアクセス

## メソッド

| メソッド | 説明 |
| --- | --- |
| [CreateInstance](sm-remotetracking-createinstance.md) | トラッキングインスタンスを作成するために使用されました |
| [CreateInstanceEx](sm-remotetracking-createinstanceex.md) | トラッキングインスタンスを作成するために使用されました |
| [GetTrackingInfo](sm-remotetracking-gettrackinginfo.md) | リモートリダイレクションサーバーに対して、配信アクションに関する情報をダウンロードすることを許可します。 |
| [GetTrackingLogs](sm-remotetracking-gettrackinglogs.md) | リダイレクトおよび web トラッキングサービスにより生成されるトラッキングログを収集できます。 |
| [GetTrackingLogs4](sm-remotetracking-gettrackinglogs4.md) | 投稿 4.00 フォーマットを使用して、リモートリダイレクトおよび web トラッキングサーバーによって生成されたトラッキングログを取得することを許可します。 |
| [PushRelayInfo](sm-remotetracking-pushrelayinfo.md) | 配信に関する情報をリモートトラッキングサーバーにアップロードできます。 |
| [PushTrackingInfo](sm-remotetracking-pushtrackinginfo.md) | リモートトラッキングサーバーで配信に関するすべての情報をアップロードすることを許可します。 |
| [RegisterInstance](sm-remotetracking-registerinstance.md) | トラッキングインスタンスの承認に使用されます |
