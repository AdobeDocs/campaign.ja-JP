# レポート

すべてのレポートパラメーターを定義します

## メソッド

| メソッド | 説明 |
| --- | --- |
| [DictionaryCheck](sm-report-dictionarycheck.md) | web アプリケーションで翻訳する文字列を検索します。 |
| [DisplayDescriptiveAnalysis](sm-report-displaydescriptiveanalysis.md) | 記述的分析の生成。 |
| [DisplayDescriptiveAnalysisEx](sm-report-displaydescriptiveanalysisex.md) | 記述的分析の生成。 |
| [ExecuteTransientQuery](sm-report-executetransientquery.md) | クエリを実行して結果をワークテーブルに保存します |
| [書き出し](sm-report-export.md) | レポートの生成とエクスポート |
| [ExportDescriptiveAnalysis](sm-report-exportdescriptiveanalysis.md) | 処理中の記述的分析をエクスポートします |
| [GenerateAnalysisWidget](sm-report-generateanalysiswidget.md) | 表示するウィジェットを生成します。 |
| [GenerateAndSaveReport](sm-report-generateandsavereport.md) | サーバーからレポートを生成してデータベースに保存します |
| [GenerateFlatReport](sm-report-generateflatreport.md) | エクスポートに使用する事前レポートの生成 |
| [GetAvailableReports](sm-report-getavailablereports.md) | 履歴なしでレポートのリストを復元します |
| [GetAvailableReportsEx](sm-report-getavailablereportsex.md) | レポートのリストを履歴なしで復元します。データの並べ替え条件とページ番号が考慮されます |
| [GetDescriptiveAnalysisData](sm-report-getdescriptiveanalysisdata.md) | クエリを実行して記述的分析のデータを取得します。 |
| [GetReportList](sm-report-getreportlist.md) | 使用可能なレポートのリストと履歴を取得します |
| [GetUsedLanguagesEnum](sm-report-getusedlanguagesenum.md) | レポートで使用される言語で列挙を作成します。 |
| [公開](sm-report-publish.md) | レポートの公開 |
| [RegisterTransientSchema](sm-report-registertransientschema.md) | クエリの結果に関連するスキーマを保存します |
| [保存](sm-report-save.md) | 既に生成済みのレポートをデータベースに保存します。 |
| [exportSaved](sm-report-exportsaved.md) | 履歴テーブルから保存されたレポートをエクスポート |

## 汎用メソッド

| メソッド | 説明 |
| --- | --- |
| [作成](f-create.md) | 特定のスキーマに対応する新しいエンティティを作成します。 |
| [load](f-load.md) | 特定のスキーマとキーに対応するエンティティを読み込んで返します。 |
| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
