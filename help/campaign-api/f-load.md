# ロード

> 警告 :
>
> ファイル API経由のアクセスは、Adobe Campaignの&#x200B;**var**、**sftp**&#x200B;および一時フォルダーに制限されています。

特定のスキーマとキーに対応するエンティティを読み込んで返します。

```text
load (key)
```

## パラメーター

**key** エンティティのキーに対応する文字列。

## 戻り値

JavaScript オブジェクトの形式でエンティティを返します。

## 備考

loadはグローバル関数ではなくスキーマメソッドです。 呼び出すには、目的のスキーマで接頭辞を付ける必要があります。 次に例を示します。

```javascript
var delivery = NLWS.nmsDelivery.load("12435")
```

このオブジェクトのプロパティとサブプロパティは自由に変更できます。 [get （） ](f-get.md) メソッドとは異なり、ドキュメントはデータベースに自動的に保存されません。オブジェクトに[save （） ](m-entity-save.md) メソッドを呼び出す必要があります。 データベース内にエンティティが見つからない場合は、エラーであり、スクリプトが中断されます。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
