# ヘルプ

テキストと画像を表示します。

![ ヘルプ コントロール ](assets/help.67cf3e33.png)

## プロパティ

**img – 文字列**&#x200B;関連する画像。

**label – 文字列**&#x200B;表示するテキスト。

## 備考

例：

```xml
      <static type="help" label="Please enter your name here."/>

<static type="help">Please enter your name here.</static>
```
