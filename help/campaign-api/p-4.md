# JavaScriptの例外

デフォルトでは、エラーが発生すると、実行中のスクリプトが中断されます。 ただし、バージョン 4.05以降では、スクリプトの処理を続行するために、エラーをキャプチャして処理できます。

Adobe Campaignで発生する例外は、エラーコード （`Number` タイプ）です。

## 例

次の使用例は、無効なアドレスからWeb ページを復元しようとし、[getUrl （） ](f-geturl.md)関数から例外を発生させます。

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
