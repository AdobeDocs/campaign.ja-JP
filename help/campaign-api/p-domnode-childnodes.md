# childNodes

テーブルの形式で子ノードのリストを返します。

```text
childNodes
```

## 備考

このプロパティは、アクセスごとに新しいテーブルを作成します。 したがって、プロパティに複数回アクセスするよりも、テーブルをローカル変数に保持することをお勧めします。

## 機能

**クラスのプロパティ：** [DOMNode](c-domnode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
