# GenerateSingleLevelDimension

フィールドに基づいて単一レベルのディメンションを生成。

```text
XML result = GenerateSingleLevelDimension ( XML dimension, XML field )
```

## パラメーター

**ディメンション** Dimensionを入力

**field** フィールドまたは式が使用されました

## 戻り値

**result**&#x200B;がディメンションを入力しました

## 機能

**スキーマ：** [xtk:olapDimension](s-xtk-olapdimension.md)

**静的：**

はい
