# textContent

ノードのテキストコンテンツ。 値はノードのタイプによって異なります。

```text
textContent
```

## 備考

このプロパティには、読み取り権限と書き込み権限でアクセスできます。

## 機能

**クラスのプロパティ：** [DOMNode](c-domnode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
