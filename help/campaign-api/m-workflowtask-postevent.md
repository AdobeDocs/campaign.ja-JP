# postEvent

トランジションをアクティブ化します。

```text
postEvent (transition)
```

## パラメーター

**移行** アクティブ化する移行。

## 戻り値

なし。

## 備考

トランジションのターゲットアクティビティがアクティブ化され、タスクの変数を受け取ります。

## 機能

**クラスのメソッド：** [WorkflowTask](c-workflowtask.md)

**次の場所で利用できます：**

* ワークフロー
