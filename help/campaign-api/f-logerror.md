# logError

ワークフローインスタンスのログにエラーメッセージを追加し、スクリプトの実行を一時停止します。

```text
logError (message)
```

## パラメーター

**message** ログに追加するメッセージ。

## 戻り値

なし。

## 備考

進行中のタスクは、エラーが発生したかのように動作します。エラーがフラグ付けされ、ワークフローが中断されます。 したがって、この関数は、ワークフローでエラーを明示的に発生させ、ワークフローを一時停止するのに役立ちます。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
