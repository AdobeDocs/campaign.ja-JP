# HttpServletResponse （クラス）

クライアントに返されるサーブレットの応答を表します。

このクラスには、`response`変数でアクセスできるインスタンスが1つしかありません。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | 応答のドキュメントタイプを変更します。 |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | 別のURLへの一時的なリダイレクトを返します。 |
| [addCookie](m-httpservletresponse-addcookie.md) | 応答にCookieを追加します。 |
| [addHeader](m-httpservletresponse-addheader.md) | 応答に追加のHTTP ヘッダーを追加します。 |
| [sendError](m-httpservletresponse-senderror.md) | パラメーターとして渡されたエラーコードを使用して、エラー応答を返します。 |

## 機能

**次の場所で利用できます：**

* JSSP
* Web アプリ
