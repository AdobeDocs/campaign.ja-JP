# isDefaultNamespace

指定された名前空間がデフォルトであるかどうかをテストします。

```text
isDefaultNamespace (namespaceURI)
```

## パラメーター

**名前空間URI**&#x200B;名前空間URI。

## 戻り値

namespaceURIがデフォルトの名前空間である場合はtrue、そうでない場合はfalseです。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
