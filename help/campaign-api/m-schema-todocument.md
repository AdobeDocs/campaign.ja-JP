# toDocument

スキーマをXML ドキュメントフォームに変換します。

```text
toDocument ()
```

## パラメーター

なし。

## 戻り値

[DOMDocument](c-domdocument.md)型オブジェクト。

## 機能

**クラスのメソッド：** [ スキーマ ](c-schema.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
