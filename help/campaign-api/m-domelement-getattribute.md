# getAttribute

属性値を返します。

```text
getAttribute (name)
```

## パラメーター

**name**&#x200B;属性名。

## 戻り値

属性テキスト値。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
