# toHexString

バッファを16進数の文字列に変換します。

```text
toHexString ()
```

## パラメーター

なし。

## 戻り値

バッファーコンテンツが16進数でエンコードされています。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
