# フォルダー

ナビゲーション階層のフォルダー

## メソッド

| メソッド | 説明 |
| --- | --- |
| [CheckEntityWriteRight](sm-folder-checkentitywriteright.md) | 現在のオペレーターに指定したエンティティへの書き込みアクセス権がある場合は「TRUE」を返します |
| [DropSelection](sm-folder-dropselection.md) | 選択項目をナビゲーションツリーのフォルダーに移動 |
| [FindFirstAuthorized](sm-folder-findfirstauthorized.md) | folderFilter 条件を満たす、現在のユーザーの最初の適格フォルダーを検索します。 |
| [HasFolderWriteRight](sm-folder-hasfolderwriteright.md) | フォルダーへの書き込みアクセス権がある場合、「TRUE」を返します |
| [InheritParentFolderRights](sm-folder-inheritparentfolderrights.md) | 親フォルダー権限でフォルダーエンティティを更新 |
| [LoadChildren](sm-folder-loadchildren.md) | 指定されたノードの子のリストを読み込む |
| [LoadChildrenWithPath](sm-folder-loadchildrenwithpath.md) | 指定されたノードの子のリストを読み込む |
| [MoveNode](sm-folder-movenode.md) | ナビゲーションツリーでフォルダーを移動 |
| [MoveSelection](sm-folder-moveselection.md) | 選択項目をナビゲーションツリーのフォルダーに移動 |
| [NewFolder](sm-folder-newfolder.md) | フォルダーを作成 |

## 汎用メソッド

| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
