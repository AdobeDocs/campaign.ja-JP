# iOSGenerateCertificate

指定されたiOS証明書をbase64でエンコードします

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## パラメーター

**fileName** ファイル名

**uuid** アプリケーション UUID

## 戻り値

**return**&#x200B;証明書のbase64 バージョン

はい
