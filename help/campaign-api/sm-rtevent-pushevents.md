# PushEvents

イベントのコレクションを挿入します。

```text
XML ids = PushEvents ( XML eventCollection )
```

## パラメーター

**eventCollection** イベント コレクション。

## 戻り値

挿入時に使用される外部識別子と内部識別子の組み合わせを含む&#x200B;**ids** コレクション。

**スキーマ：** [nms:rtEvent](s-nms-rtevent.md)

はい
