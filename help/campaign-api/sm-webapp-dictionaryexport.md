# DictionaryExport

翻訳する文字列をエクスポートします。

```text
XML files = DictionaryExport ( XML where, Number exportOption, String exportFormat )
```

## パラメーター

**どこ**&#x200B;を選択します。

**exportOption**&#x200B;書き出しオプション

**exportFormat**&#x200B;書き出し形式

## 戻り値

**files**&#x200B;出力ファイルの説明
