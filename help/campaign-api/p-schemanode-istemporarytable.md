# isTemporaryTable

テーブルが一時テーブルかどうかを示すブール値を返します。 データベースの作成中にテーブルは作成されません。

```text
isTemporaryTable
```

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
