# SQLName

フィールドのSQL名。 オブジェクトがSQL型フィールドでない場合、プロパティは空の文字列です。

```text
SQLName
```

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
