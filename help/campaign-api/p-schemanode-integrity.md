# 企業倫理

リンクの整合性タイプを返します。

```text
integrity
```

## 備考

プロパティには、次のいずれかの値を指定できます。

* Schema.INTEGRITY\_NORMAL - 「標準」タイプのリンク。
* Schema.INTEGRITY\_DEFINE - &quot;Define&quot; type link.
* Schema.INTEGRITY\_NEUTRAL - &quot;ニュートラル&quot; タイプのリンク。
* Schema.INTEGRITY\_USED - &quot;used&quot; type link.
* Schema.INTEGRITY\_OWN - &quot;own&quot; type link.
* Schema.INTEGRITY\_OWNCOPY - &quot;owncopy&quot; タイプのリンク。

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

* 配信プロパティ

* JSSP

* Web アプリ
