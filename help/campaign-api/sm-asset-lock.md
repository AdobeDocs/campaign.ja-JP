# ロック

現在のユーザーのリソースをロックして、リソースが変更中であることを他のユーザーに通知します

```text
Lock ( String assetId )
```

## パラメーター

**assetId** リソース ID。

## 戻り値

なし。

## 機能

**スキーマ：** [nms:asset](s-nms-asset.md)

**静的：**

はい
