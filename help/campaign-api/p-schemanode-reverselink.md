# reverseLink

要素がリンクの場合、（ターゲットスキーマを介して）逆リンクを表す[SchemaNode](c-schemanode.md) オブジェクトを返します。 そうでない場合、プロパティは定義されません。

```text
reverseLink
```

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
