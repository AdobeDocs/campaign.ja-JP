# 廃棄する

オブジェクトで使用されるリソースを解放します。

```text
dispose ()
```

## パラメーター

なし。

## 戻り値

なし。

## 備考

このメソッドは、ガベージコレクターまたはスクリプトの最後でオブジェクトが最終処理されるのを待たずに、オブジェクトが使用するリソースを解放するのに便利です。

## 機能

**クラスのメソッド：** [ZipFile](c-zipfile.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
