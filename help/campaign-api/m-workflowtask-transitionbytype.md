# transitionByType

指定された型に対応する遷移を返します。

```text
transitionByType (type)
```

## パラメーター

**type** トランジションのタイプ。

## 戻り値

タイプをパラメーターとして渡す最初のトランジション。アクティビティにこのタイプのトランジションがない場合はnull。

## 機能

**クラスのメソッド：** [WorkflowTask](c-workflowtask.md)

**次の場所で利用できます：**

* ワークフロー
