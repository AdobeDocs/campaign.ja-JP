# CheckAccess

現在のオペレーターがタスクにアクセスできるかどうかを確認します。

```text
Boolean result = CheckAccess ( XML taskEntity )
```

## パラメーター

**taskEntity** タスク エンティティ

## 戻り値

**result** メソッドの戻り値（yes/no）

## 機能

**スキーマ：** [nms:task](s-nms-task.md)

**静的：**

はい
