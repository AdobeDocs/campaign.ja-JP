# deleteData

テキストの一部を削除します。

```text
deleteData (offset, count)
```

## パラメーター

**offset**&#x200B;削除する最初の文字の位置（最初の文字は0）。

**count**&#x200B;削除する文字数。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMCharacterData](c-domcharacterdata.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
