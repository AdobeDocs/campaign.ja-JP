# BuildTableList

テーブル名のリストを取得します。

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## パラメーター

データソースの&#x200B;**dataSource** ID

テーブル名の&#x200B;**tablePattern** マスク

## 戻り値

既存のテーブルの&#x200B;**tableList** リスト

**スキーマ：** [xtk:sqlSchema](s-xtk-sqlschema.md)
