# GenerateLinkDimension

リンクに基づいてディメンションを生成します。

```text
XML result = GenerateLinkDimension ( XML dimension, XML linklevels )
```

## パラメーター

**ディメンション** Dimensionを入力

**linklevels**&#x200B;利用可能なレベル

## 戻り値

**result**&#x200B;がディメンションを入力しました

**スキーマ：** [xtk:olapDimension](s-xtk-olapdimension.md)
