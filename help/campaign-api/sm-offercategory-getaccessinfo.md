# GetAccessInfo

匿名モードの継承プロパティを返します。

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## パラメーター

**categoryId** カテゴリ ID

## 戻り値

**匿名** カテゴリーオファーが匿名かどうかを指定します

**parentAnonymous**&#x200B;親カテゴリのオファーが匿名かどうかを指定します

## 機能

**スキーマ：** [nms:offerCategory](s-nms-offercategory.md)

**静的：**

はい
