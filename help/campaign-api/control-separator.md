# 区切り記号

テキストと画像で区切り記号を表示します。

![区切り記号コントロール ](assets/separator.70317a27.png)

## プロパティ

**方向 – デフォルトでは文字列**&#x200B;水平方向。

**img – 文字列**&#x200B;関連する画像。

**label – 文字列**&#x200B;表示するテキスト。

## 備考

例：

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
