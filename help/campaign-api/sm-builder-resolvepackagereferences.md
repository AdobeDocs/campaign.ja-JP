# ResolvePackageReferences

パッケージ内の依存関係を解決します

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## パラメーター

インポートするパッケージを含む&#x200B;**parameters** XML要素。

## 戻り値

**patchedPackage**&#x200B;処理済みパッケージ。

**warningNb**&#x200B;生成された警告の数。

**スキーマ：** [xtk:builder](s-xtk-builder.md)

はい
