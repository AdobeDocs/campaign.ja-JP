# 遷移

アクティビティのトランジションのリストを返します。

```text
transitions ()
```

## パラメーター

なし。

## 戻り値

アクティビティが定義されている順序で、アクティビティのすべての遷移を含むテーブル。

**クラスのメソッド：** [WorkflowTask](c-workflowtask.md)
