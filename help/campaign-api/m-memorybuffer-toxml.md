# toXML

[MemoryBuffer](c-memorybuffer.md)の内容から取得したXML JavaScript オブジェクトを返します。 この関数は廃止されました。[toDocument （） ](m-memorybuffer-todocument.md)を使用してください

```text
toXML ( [codePage ])
```

## パラメーター

**codePage**&#x200B;使用する文字のページをコーディングする整数。 デフォルトでは、MemoryBuffer.CODEPAGE\_UTF8。

## 戻り値

XML オブジェクトの形式のスタンプの内容。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
