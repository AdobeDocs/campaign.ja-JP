# ファイル

ファイルに関連付けられた新しいオブジェクトを作成します。

```text
File (filename)
```

## パラメーター

**filename**&#x200B;読み取りまたは作成するファイルの名前。

## 戻り値

なし。

## 備考

例：

```javascript
var f = new File("/tmp/file.txt")
```

## 機能

**クラスのメソッド：** [&#x200B; ファイル &#x200B;](c-file.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
