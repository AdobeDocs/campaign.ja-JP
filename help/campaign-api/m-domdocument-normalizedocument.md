# normalizeDocument

ドキュメントを正規化します。エンティティ参照は置き換えられ、隣接するテキストノードはフュージョン化されます。

```text
normalizeDocument ()
```

## パラメーター

なし。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
