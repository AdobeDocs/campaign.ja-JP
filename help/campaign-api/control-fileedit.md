# FileEdit

このコントロールを使用すると、ファイル名を入力できます。

![FileEdit コントロール ](assets/fileedit.56228d2a.png)

## プロパティ

**backColor – 文字列**&#x200B;背景色（btnshasow、白）。

**border - string** コントロール中に境界線スタイルを変更します（実線、倍線、インセット、アウトセット、なし）。

**dlgType – 文字列** ファイル選択ウィンドウのタイプ（保存、opendir、savedir）。

**filters - string** フィルターのリスト

**font-size - integer** フォントサイズを変更します。

**label – 文字列**&#x200B;関連ラベル。

**lastPath - string** ファイル選択ウィンドウのパス。

**loadContent - ブール値** ファイルのコンテンツを読み込みます。

**ノーラベル – ブール値**&#x200B;関連するラベルを非表示にします。

**readOnly - ブール値**&#x200B;は、コントロールを強制的に読み取り専用にします。

**必須 – ブール値** フィールドは必須です。

**title - string**&#x200B;選択ウィンドウのタイトル

**xpathCopyName - xpath** ファイル名を保存するためのパス（拡張子が付いています）。

**xpathType - xpath** ファイルの種類（テキストまたはXML）
