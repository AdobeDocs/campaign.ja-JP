# PublishIfNeededFromId

必要に応じてリソース ID を使用してメディアサーバー上のファイルをコピーします

```text
PublishIfNeededFromId ( String fileResId )
```

## パラメーター

**fileResId** ファイル ID

## 戻り値

なし。
