# CleanupDeliveries

ミッドソーシングサーバーが特定の配信を削除することを指定します。

```text
CleanupDeliveries ( String deliveryId )
```

## パラメーター

**deliveryId**&#x200B;送信データベース内の配信識別子のリスト （コンマ区切り）

## 戻り値

なし。

**スキーマ：** [nms:delivery](s-nms-delivery.md)

**静的：**

はい
