# doneTransition

アクティビティの「完了」トランジションを返します。

```text
doneTransition ()
```

## パラメーター

なし。

## 戻り値

最初の「完了」アクティビティが見つかった場合はnullです。

## 機能

**クラスのメソッド：** [WorkflowTask](c-workflowtask.md)

**次の場所で利用できます：**

* ワークフロー
