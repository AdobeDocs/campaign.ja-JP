# MoveSelection

```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## パラメーター

**schemaId**&#x200B;選択スキーマ ID

宛先フォルダーの&#x200B;**entityFolder** ID

移動する&#x200B;**selectionList**&#x200B;の選択範囲

**key** ノードキー

## 戻り値

なし。
