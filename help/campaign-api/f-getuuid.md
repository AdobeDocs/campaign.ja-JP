# getUUID

一意のID （ユニバーサル固有ID）の生成。

```text
getUUID ()
```

## パラメーター

なし。

## 戻り値

「550E8400-E29B-41D4-A716-446655440000」タイプの一意のIDを含む文字の文字列。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
