# 保存

アーカイブを保存します。

```text
save ( [filename ] [, overwrite ])
```

## パラメーター

**filename** アーカイブの名前。 名前が指定されていないか空の場合、アーカイブは元の名前で保存されます。

**overwrite** &#39;false&#39;の場合、この名前のファイルが既に存在する場合、アーカイブは保存されず、例外が発生します。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [ZipFile](c-zipfile.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
