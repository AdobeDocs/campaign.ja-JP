# DOMElement （クラス）

エレメントタイプノード。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [toXMLString](m-domelement-toxmlstring.md) | エレメントを文字列に変換します。 |
| [getFirstElement](m-domelement-getfirstelement.md) | 指定された条件を検証して、最初の子要素を返します。 |
| [hasElement](m-domelement-haselement.md) | 指定された条件を検証して、要素に子要素があるかどうかをテストします。 |
| [getValue](m-domelement-getvalue.md) | 指定されたXPathで参照されるノード値を返します。 |
| [getBooleanValue](m-domelement-getbooleanvalue.md) | 指定されたXPathで参照されるボーリアンノード値を返します。 |
| [getDateValue](m-domelement-getdatevalue.md) | 指定されたXPathによるノード参照のdate+hour タイプ値を返します。 |
| [getNumberValue](m-domelement-getnumbervalue.md) | 指定されたXPathで参照されるデジタルノード値を返します。 |
| [getElements](m-domelement-getelements.md) | 指定した名前の子要素のリストを返します。この要素に属します。 |
| [getAttribute](m-domelement-getattribute.md) | 属性値を返します。 |
| [setAttribute](m-domelement-setattribute.md) | 属性の値を変更するか、新しい属性を作成します。 |
| [removeAttribute](m-domelement-removeattribute.md) | 属性を削除します。 |
| [getElementsByTagName](m-domelement-getelementsbytagname.md) | 指定した名前を持つすべての子要素のリストを返します。 |
| [getAttributeNS](m-domelement-getattributens.md) | 属性値を返します。 |
| [setAttributeNS](m-domelement-setattributens.md) | 属性の値を変更するか、新しい属性を作成します。 |
| [removeAttributeNS](m-domelement-removeattributens.md) | 属性を削除します。 |
| [getElementsByTagNameNS](m-domelement-getelementsbytagnamens.md) | 指定した名前を持つすべての子要素のリストを返します。 |
| [hasAttribute](m-domelement-hasattribute.md) | 属性の存在をテストします。 |
| [hasAttributeNS](m-domelement-hasattributens.md) | 属性の存在をテストします。 |
| [setIdAttribute](m-domelement-setidattribute.md) | 指定した属性をID タイプ属性として宣言します。 |
| [setIdAttributeNS](m-domelement-setidattributens.md) | 指定した属性をID タイプ属性として宣言します。 |

## プロパティ

| プロパティ | 説明 |
| --- | --- |
| [tagName](p-domelement-tagname.md) | エレメント名。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
