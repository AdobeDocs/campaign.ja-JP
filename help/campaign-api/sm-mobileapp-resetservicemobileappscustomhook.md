# resetServiceMobileAppsCustomHook

同じサービスに含まれるすべてのモバイルアプリ向けの Web サービスの追加パラメーターを消去します

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## パラメーター

現在のサービスノードの&#x200B;**serviceContent** コンテンツ

## 戻り値

**serviceOut**&#x200B;処理後のサービスノードのコンテンツ

## 機能

**スキーマ：** [nms:mobileApp](s-nms-mobileapp.md)

**静的：**

はい
