# DiagnoseHTML

HTML コンテンツの診断を開始します

```text
XML diagnostic = DiagnoseHTML ( String htmlContent, Number format )
```

## パラメーター

**htmlContent** チェックするHTML コンテンツ

**format** メール形式

## 戻り値

**diagnostic**&#x200B;診断を返します
