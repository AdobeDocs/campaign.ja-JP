# CheckEntityWriteRight

現在のオペレーターに指定したエンティティへの書き込みアクセス権がある場合は「TRUE」を返します

```text
Boolean result = CheckEntityWriteRight ( String schema, String key )
```

## パラメーター

**スキーマ** エンティティ スキーマ ID

**key** エンティティのプライマリキーの値

## 戻り値

**result**&#x200B;結果

## 機能

**スキーマ：** [xtk:folder](s-xtk-folder.md)

**静的：**

はい
