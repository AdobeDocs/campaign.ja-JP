# HttpSoapConnection （クラス）

SOAP サーバーへのHTTP接続を表します。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [HttpSoapConnection](m-httpsoapconnection-httpsoapconnection.md) | SOAP サーバーへのHTTP接続を作成します。 |
| [addHeader](m-httpsoapconnection-addheader.md) | HTTP ヘッダーを追加します |
| [破棄](m-httpsoapconnection-dispose.md) | オブジェクトで使用されるリソースを解放します。 |
| [setHeader](m-httpsoapconnection-setheader.md) | HTTP ヘッダーを指定します。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
