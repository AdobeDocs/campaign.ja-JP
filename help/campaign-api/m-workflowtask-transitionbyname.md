# transitionByName

指定された名前に対応するトランジションを返します。

```text
transitionByName (name)
```

## パラメーター

**name**&#x200B;移行の名前。

## 戻り値

名前をパラメーターとして渡したトランジション。アクティビティにこの名前のトランジションがない場合はnull。

## 機能

**クラスのメソッド：** [WorkflowTask](c-workflowtask.md)

**次の場所で利用できます：**

* ワークフロー
