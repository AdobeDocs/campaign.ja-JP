# applyXsl

XSL スタイルシートを使用してXML ドキュメントを変換します。

```text
applyXsl (xslEntity, xml)
```

## パラメーター

**xslEntity** データベースに保存されているXSL スタイルシートの名前。

**xml**&#x200B;変換するXML ドキュメントまたはXML ドキュメントを含む文字列。

## 戻り値

変換後の文字列の形式のXML ドキュメント。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
