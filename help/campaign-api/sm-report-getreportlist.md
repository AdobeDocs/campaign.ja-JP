# GetReportList

```text
XML reports = GetReportList ( String activeContext, String schema, String selection, String locationName )
```

## パラメーター

**activeContext** アクティブなコンテキスト （選択範囲、グローバル）

**スキーマ** スキーマが含まれています

**selection**

**locationName**

**レポート**&#x200B;対象となるレポートのリスト
