# logWarning

ワークフローインスタンスのログに警告メッセージを追加します。

```text
logWarning (message)
```

## パラメーター

**message** ログに追加するメッセージ。

## 戻り値

なし。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
