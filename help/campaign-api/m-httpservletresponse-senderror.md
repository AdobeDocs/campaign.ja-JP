# sendError

パラメーターとして渡されたエラーコードを使用して、エラー応答を返します。

```text
sendError (errorCode)
```

## パラメーター

**errorCode** HTTP エラーコード。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [HttpServletResponse](c-httpservletresponse.md)

**次の場所で利用できます：**

* JSSP
* Web アプリ
