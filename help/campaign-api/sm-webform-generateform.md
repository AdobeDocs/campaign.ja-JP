# GenerateForm

メールまたは Web モードでフォームを生成します

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## パラメーター

**formName** フォーム名

**mailMode** メール形式のフォームを生成

## 戻り値

**result** フォーム上のXSLの適用の結果

## 機能

**スキーマ：** [nms:webForm](s-nms-webform.md)

**静的：**

はい
