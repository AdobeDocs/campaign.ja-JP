# formatDate

日付を文字列として書式設定します。

```text
formatDate (date, format [, timeZone ])
```

## パラメーター

**date** コンバージョンする日付。

**format**&#x200B;使用する形式を表す文字列。 日付の様々な部分の書式設定に使用される文字は次のとおりです。

* Y – 年
* M – 年の月（1 ～ 12）
* B – 月名
* D – 月の日（1 ～ 31）
* A – 日付の名前
* J – 年の日（1-366）
* W – 年の週
* H – 時間（0 ～ 23）
* I – 時間（1 ～ 12）
* N – 分（0 ～ 59）
* S – 秒（0 ～ 59）
* P – 午前/午後

これらの文字の特定の文字の前に数字を指定できます。 AとBの文字の後には、短縮バージョンではなくフルネームを使用する場合はl、英語で名前を使用する場合はiを使用できます。 例：

* &quot;%4Y/%2M/%2D&quot; => 2000/01/24.
* “ %A %D %B %4Y ” => 2000年1月24日（月）。
* &quot;%Al %D %Bl %4Y&quot; => 2000年1月24日月曜日。
* 「%02H:%02N:%02S」は、時間、分、秒を2つの数値に表示します。

**timeZone** タイムゾーンに対応する文字列数。 使用可能な値は、xtk:common: タイムゾーン列挙スキーマで指定されます。

## 戻り値

要求された形式の日付を表す文字列。
