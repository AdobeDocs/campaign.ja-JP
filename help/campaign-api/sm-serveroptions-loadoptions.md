# LoadOptions

> 警告：この関数は、オンプレミス環境で使用できます。

サーバーオプションを読み込みます

```text
XML result = LoadOptions ( XML select )
```

## パラメーター

**select** ロードするオプションのXPathを選択

## 戻り値

**result**&#x200B;更新オプション ドキュメント

## 機能

**スキーマ：** [xtk:serverOptions](s-xtk-serveroptions.md)

**静的：**

はい
