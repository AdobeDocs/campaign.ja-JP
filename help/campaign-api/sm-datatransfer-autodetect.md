# 自動検出

自動検出を開始して、ファイルの最初のラインを返します

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## パラメーター

**fileName** ファイル名

**codepage**&#x200B;文字エンコーディング

## 戻り値

**result** ファイルの最初の行を返します

## 機能

**スキーマ：** [xtk:dataTransfer](s-xtk-datatransfer.md)

**静的：**

はい
