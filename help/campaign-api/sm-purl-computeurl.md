# ComputeUrl

この pURL にアクセスするための URL を生成します

```text

```

## パラメーター

**purl**&#x200B;現在のpurl。

## 戻り値

**url** URL （技術）

**exampleUrl** URLに架空のデータが含まれています（表示用）
