# GenerateFromId

フォルダー内の識別子で参照されたコンテンツを生成して公開します

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## パラメーター

**id** コンテンツ ID

**publishingDir**&#x200B;公開フォルダー

## 戻り値

**outputFiles**&#x200B;生成されたファイルのリスト
