# appendData

テキストに文字列を追加します。

```text
appendData (arg)
```

## パラメーター

追加する&#x200B;**arg**&#x200B;文字の文字列。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMCharacterData](c-domcharacterdata.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
