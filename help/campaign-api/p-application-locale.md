# ロケール

インスタンスのローカルに一致する文字列を返します。

```text
locale
```

## 備考

ローカルは、地域設定を定義するコードです。 これは、言語コードの後に国コードが続き、「 – 」で区切られた部分で構成されます。 値の例：

* en-US – 英語、アメリカ合衆国
* en-GB – 英語、イギリス
* fr-FR - フランス語、フランス語
* de-DE - ドイツ語、ドイツ語
* es-ES - スペイン語，スペイン
