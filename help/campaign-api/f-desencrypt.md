# DESencrypt

> 警告 :
>
> この関数は廃止されました。[cryptString （） ](f-cryptstring.md)を使用してください。

DES アルゴリズムを使用して文字列をデジタル化します。

```text
DESencrypt (value [, key ] [, cipher mode ] [, initialization vector ] [, padding ])
```

## パラメーター

**value** デジタル化する文字列

**key** キーは16進数で表されます。 キーの長さは64 ビット、つまり16進数の文字である必要があります。 デフォルトでは、データベースの識別子が使用されます。

**暗号モード** ブロックエンコーディングメソッド。 1文字の文字列。 つまり、「CBC」、「ECB」、「EDE」です。 デフォルトでは「CBC」です。

**初期化ベクトル** 16進数文字列の形式の初期化ベクトル。 正確に8 オクテット、つまり16文字です。 デフォルトでは空の文字列。

**パディング** パディングの種類。 文字列（例：「PKCS5PADDING」または「PKCS7PADDING」） デフォルトでは、空の文字列です。つまり、暗号化する文字列の末尾に「\\0」が追加されます。

## 戻り値

ベース 64で表されるデジタル化された文字列。

## 備考

* DES鍵は56の有用なビットと8のビットを持ち、パリティのために使われる。
* DES アルゴリズムによって効果的に暗号化される値は、文字列の8 ビット Windows-1252表現で、ASCII 0文字で終わり、バイナリゼロで64 ビットの倍数にパディングされます。
* デジタル化された値は、複数の長さ64 ビットの値を持ちます。
