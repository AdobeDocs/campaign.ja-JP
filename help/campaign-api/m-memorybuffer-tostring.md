# toString

[MemoryBuffer](c-memorybuffer.md)の内容を文字列の形式で返します。

```text
toString ( [codePage ])
```

## パラメーター

**codePage**&#x200B;使用される文字のページをコーディングする整数。 デフォルトでは、MemoryBuffer.CODEPAGE\_UTF8。

## 戻り値

文字列の形式のスタンプの内容。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
