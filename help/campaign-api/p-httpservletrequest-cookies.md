# cookie

クエリのCookieを返します。

```text
cookies
```

## 備考

cookie プロパティは、各プロパティに一致するcookieを含むオブジェクトを返します。 例：

```javascript
var cookies = request.cookies
for(var name in cookies)
{
var value = cookies[name].value
document.write(name + " : " + value + "<br>")
}
```

## 機能

**クラスのプロパティ：** [HttpServletRequest](c-httpservletrequest.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* JSSP
* Web アプリ
