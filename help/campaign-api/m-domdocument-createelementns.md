# createElementNS

指定された名前と名前空間を持つ新しい要素を作成します。

```text
createElementNS (namespaceURI, qualifiedName)
```

## パラメーター

**名前空間URI**&#x200B;名前空間URI。

**qualifiedName**&#x200B;作成する要素の修飾名。

## 戻り値

[要素](c-domelement.md)が作成されました。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
