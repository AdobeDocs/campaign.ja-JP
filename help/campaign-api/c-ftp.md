# FTP （クラス）

FTP オブジェクトを使用すると、FTP プロトコルを使用して多数の操作を実行できます。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [FTP](m-ftp-ftp.md) | FTP コマンドを実行する新しいオブジェクトを作成します。 |
| [破棄](m-ftp-dispose.md) | オブジェクトで使用されるリソースを解放します。 |
| [ リスト ](m-ftp-list.md) | 指定したディレクトリ内のサーバー上のファイルのリストを返します。 |
| [ ダウンロード ](m-ftp-download.md) | サーバーからローカルファイルまたはメモリにファイルをダウンロードします。 |
| [ アップロード ](m-ftp-upload.md) | ローカルファイルからFTP サーバーにファイルをダウンロードします。 |
| [setFile](m-ftp-setfile.md) | 転送モードと受信ファイルを定義します。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
