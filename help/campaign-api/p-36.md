# ディレクティブページ

関数または文字列のライブラリが含まれます。

## 構文

&lt;%@ page import=&quot;lib1, ...&quot; %> &lt;%@ page stringGroup=&quot;groupName&quot; %>

## 説明

文字列のライブラリを読み込むと、名前がsg\_で始まり、その後に特殊文字が&#39;\_&#39;に置き換えられたライブラリの名前が続くグローバル JavaScript オブジェクトが表示されます。 例えば、nms:campaignを含めると、sg\_nms\_campaign変数が作成されます。

## 例

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
