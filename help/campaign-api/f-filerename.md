# fileRename

ファイル名を変更します。

文字エンコーディングが指定されていない場合は、サーバーのデフォルトが使用されます。

```text
fileRename (oldname, newname)
```

## パラメーター

**oldname**&#x200B;名前を変更するファイルのフルネーム。

**newname** ファイルの新しい名前。

## 戻り値

なし。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
