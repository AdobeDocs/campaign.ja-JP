# KillSession

> 警告：この関数は、オンプレミス環境で使用できます。

指定されたセッションを閉じます

```text
KillSession ( String Id )
```

## パラメーター

**Id** ログイン IDまたはセッション ID

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:session](s-xtk-session.md)

**静的：**

はい
