# addCookie

応答にCookieを追加します。

```text
addCookie (cookie)
```

## パラメーター

追加する&#x200B;**cookie** Cookie。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [HttpServletResponse](c-httpservletresponse.md)

**次の場所で利用できます：**

* JSSP
* Web アプリ
