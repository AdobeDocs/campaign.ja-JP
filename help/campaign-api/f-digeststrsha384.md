# digestStrSha384

文字列のSHA-384 ハッシュを計算します。 文字列は、計算の前にUTF-8で自動的にエンコードされます。

```text
digestStrSha384 (string)
```

## パラメーター

**文字列** ハッシュを計算する文字列。

## 戻り値

パラメーターとして渡された文字列のSHA-384 ハッシュ。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
