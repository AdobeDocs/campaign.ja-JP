# AddInstance

> 警告：この関数は、オンプレミス環境で使用できます。

サーバー上で新しいインスタンスを宣言します

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## パラメーター

作成するインスタンスの&#x200B;**instanceName**&#x200B;名

インスタンスに関連付けられている&#x200B;**ホスト** DNS マスク

**lang** インスタンス言語

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:serverOptions](s-xtk-serveroptions.md)

**静的：**

はい
