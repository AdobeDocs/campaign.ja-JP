# md5

スキーマのMD5 コードを16進数文字列の形式で指定します。

```text
md5
```

## 機能

**クラスのプロパティ：** [&#x200B; スキーマ &#x200B;](c-schema.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
