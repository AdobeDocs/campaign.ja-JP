# DictionaryImport

CXV または XLIFF ファイルを使用して翻訳された文字列をインポートします。

```text
DictionaryImport ( String fileName )
```

## パラメーター

**fileName** インポートするファイルまたはアーカイブの名前。

## 戻り値

なし。

はい
