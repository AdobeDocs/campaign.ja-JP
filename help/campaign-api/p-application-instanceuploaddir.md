# instanceUploadDir

スクリプトが実行されるインスタンスの「アップロード」ディレクトリのフルパス。

```text
instanceUploadDir
```

## 備考

返される値は、サーバーパラメーター内のアップロードディレクトリのオーバーロードの可能性を考慮に入れます。

## 機能

**クラスのプロパティ：** [ アプリケーション ](c-application.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
