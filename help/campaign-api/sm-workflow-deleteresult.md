# DeleteResult

1つ以上のアクティビティの結果を消去します。

```text
DeleteResult ( String workflowId, String activityName )
```

## パラメーター

**workflowId** ワークフローの識別子または内部名。

**activityName**&#x200B;結果を消去するアクティビティの名前

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:workflow](s-xtk-workflow.md)

**静的：**

はい
