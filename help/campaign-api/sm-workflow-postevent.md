# PostEvent

任意の種類のアクティビティからイベントを生成します。

```text
PostEvent ( String workflowId, String activity, String transition, XML parameters, Boolean complete )
```

## パラメーター

**workflowId** ワークフローの識別子または内部名。

**アクティビティ** イベントの開始元となるアクティビティの名前

**transition** アクティブ化するトランジションの名前。 この名前が空の場合、イベントは最初の有効な移行で発行されます（有効期限タイプイベントは無視されます）。

**パラメーター** XML要素の形式のイベントのパラメーター。 要素の名前は変数である必要があります。 変数を渡したくない場合は、空の要素&lt;variables/>または空の文字列&quot;&quot;を使用できます。

**complete**&#x200B;指定したアクティビティのすべての保留中のタスクが完了しました。

## 戻り値

なし。

## 備考

* コマンドは非同期モードで実行され、メソッドの戻り後に即座に影響を与えません。
* このメソッドが呼び出されたときに、ターゲットワークフローを開始する必要があります。 起動しない場合は、対応するログファイルにエラーが書き込まれます。
* メソッドの呼び出し時にターゲットワークフローが中断された場合、ワークフローが再開されるまでコマンドはキューに残されます。
* アクティビティに制限はありません。タスクを進行中にしたり、完了したりする必要はありません。
