# insertBefore

特定の位置の前にノードを挿入します。

```text
insertBefore (newChild, refChild)
```

## パラメーター

挿入する&#x200B;**newChild** ノード。

**refChild**&#x200B;挿入するノードに続く必要がある子ノード。

## 戻り値

挿入されたノード。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
