# GetCleanedValue

クレンジングした値を取得します。

```text
String value = GetCleanedValue ( Number enumId, String alias )
```

## パラメーター

**enumId**&#x200B;列挙ID

置換する&#x200B;**エイリアス**&#x200B;値

## 戻り値

**value** クレンジングされた値（見つからない場合は、エイリアスを返します）
