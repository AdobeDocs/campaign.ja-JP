# createTextNode

新しいテキストタイプノードを作成します。

```text
createTextNode (data)
```

## パラメーター

**data** テキストノードに挿入する文字列。

## 戻り値

[DOMCharacterData](c-domcharacterdata.md)型ノードが作成されました。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
