# removeChild

ノードを削除します。

```text
removeChild (oldChild)
```

## パラメーター

**oldChild** ノードを削除します。

## 戻り値

ノードを削除しました。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
