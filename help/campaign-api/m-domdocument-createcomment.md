# createComment

新しいコメントタイプノードを作成します。

```text
createComment (data)
```

## パラメーター

コメント ノードに挿入する&#x200B;**data**&#x200B;文字の文字列。

## 戻り値

[&#x200B; コメント &#x200B;](c-domcharacterdata.md)が作成されました。
