# getOption

オプションテーブルのオプションの値を返します。

```text
getOption (name [, useCache ])
```

## パラメーター

**name** オプションの名前。

**useCache** オプション値キャッシュを使用します（デフォルトでは使用されません）。

## 戻り値

オプションが存在する場合はオプションの値、それ以外の場合は未定義です。 値のタイプは、オプションのタイプによって異なります。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
