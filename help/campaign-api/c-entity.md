# エンティティ （クラス）

特定のスキーマのデータベースのエンティティを表します。

このようなオブジェクトは直接インスタンス化できません。 メソッド create （）、get （）またはload （）を使用する必要があります。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
