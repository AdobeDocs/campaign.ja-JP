# RestartTask

完了した1つ以上のタスクを強制的に再開します。

```text
RestartTask ( String workflowId, String activityName )
```

## パラメーター

**workflowId** ワークフローの識別子または内部名。

**activityName**&#x200B;再起動するアクティビティの名前

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:workflow](s-xtk-workflow.md)

**静的：**

はい
