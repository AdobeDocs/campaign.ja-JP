# DOMAttr （クラス）

属性タイプノード。

## プロパティ

| プロパティ | 説明 |
| --- | --- |
| [isId](p-domattr-isid.md) | 属性がID タイプの場合はtrueです。 |
| [name](p-domattr-name.md) | 属性名： |
| [ownerElement](p-domattr-ownerelement.md) | この属性またはnullを持つ要素。 |
| [指定](p-domattr-specified.md) | 値が明示的に指定されている場合はtrueです（デフォルトでは暗黙的な値ではありません）。 |
| [値](p-domattr-value.md) | 属性テキスト値。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
