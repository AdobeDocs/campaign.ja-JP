# toXMLString

XML ドキュメントを文字列に変換します。

```text
toXMLString (format)
```

## パラメーター

**format** XML ドキュメントを書式設定するためのブール値。

## 戻り値

なし。

## 備考

このメソッドは、要素に関する同じ名前のメソッドとは異なり、prologを追加します。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
