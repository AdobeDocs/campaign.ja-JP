# 列挙

現在のノードにリンクされている列挙である[列挙](c-enumeration.md) オブジェクトを返します。列挙がない場合はnullを返します。

```text
enumeration
```

## 機能

**クラスのプロパティ：** [SchemaNode](c-schemanode.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
