# hasChildNodes

ノードに少なくとも1つのサブフォルダーがあるかどうかをテストします。

```text
hasChildNodes ()
```

## パラメーター

なし。

## 戻り値

ノードに少なくとも1人の子がある場合はtrue、それ以外の場合はfalse。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
