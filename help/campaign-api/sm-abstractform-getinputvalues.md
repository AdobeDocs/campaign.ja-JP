# GetInputValues

フォーム内の入力ゾーンに指定可能な値を検索します。

```text
XML options = GetInputValues ( String schema, XML input )
```

## パラメーター

**スキーマ**&#x200B;調査編集スキーマ。

**input**&#x200B;入力ゾーン。

## 戻り値

**options**&#x200B;この入力ゾーンの可能な値。

## 機能

**スキーマ：** [xtk:abstractForm](s-xtk-abstractform.md)

**静的：**

はい
