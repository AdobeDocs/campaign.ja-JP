# computeString

現在の演算子の説明文字列を返します。 デフォルトでは、これはオペレーターの名前の後にログインが続きます。

```text
computeString
```

## 機能

**クラスのプロパティ：** [CurrentOperator](c-currentoperator.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
