# AliasCleansing

クレンジングした列挙を使用してデータベースを更新します。

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## パラメーター

**where**&#x200B;列挙フィルター。

**fromDate** アンケート回答の開始日。

**refreshHit**&#x200B;更新をヒットします。

**resetHit**&#x200B;最初から更新をヒットします。

## 戻り値

なし。
