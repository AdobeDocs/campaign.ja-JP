# GetNewIds

データベースの内部キー識別子のリストを収集します。

```text
String idList = GetNewIds ( Number count )
```

## パラメーター

**count**&#x200B;このメソッドが返す識別子の数

## 戻り値

**idList**&#x200B;識別子のコンマ区切りリスト
