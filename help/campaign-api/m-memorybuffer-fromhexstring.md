# fromHexString

バッファーに16進数文字列の内容を読み込みます。

```text
fromHexString (string)
```

## パラメーター

**文字列** バッファーに追加する16進数でエンコードされたバイナリ データを表す文字列です。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
