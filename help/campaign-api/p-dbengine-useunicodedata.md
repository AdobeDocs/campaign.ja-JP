# useUnicodeData

データベースにUnicode データが含まれている場合はtrueを返します。

```text
useUnicodeData
```

## 機能

**クラスのプロパティ：** [DBEngine](c-dbengine.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
