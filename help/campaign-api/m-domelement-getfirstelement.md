# getFirstElement

指定された条件を検証して、最初の子要素を返します。

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## パラメーター

**tagName**&#x200B;検索された要素の名前。

**attrName**&#x200B;特定の値を検証する必要がある属性の名前。

**attrValue**&#x200B;属性値。

## 戻り値

指定された条件またはnullを検証する最初の要素。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
