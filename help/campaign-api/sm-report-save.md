# 保存

既に生成済みのレポートをデータベースに保存します。

```text
XML result = Save ( XML data, String reportName )
```

## パラメーター

レポートで使用される&#x200B;**data** データ

**reportName** レポートの内部名

## 戻り値

**結果**&#x200B;一意のIDとレコード日
