# hmacStr

文字列のMD5、SHA-1またはSHA-256 ハッシュを計算します。 文字列は、計算の前にUTF-8で自動的にエンコードされます。

```text
hmacStr (string [, key ] [, algo ])
```

## パラメーター

**文字列** ハッシュを計算する文字列。

**key** キー（文字列形式）。 自動的にUTF-8に変換されます。 キーが見つからない場合、サーバーはインスタンスに依存し、このインスタンスでのみ有効なキーを使用します。

**algo**&#x200B;使用するハッシュの種類。 使用可能な値は、「MD5」、「SHA1」または「SHA256」です。 大文字と小文字の区別は無視されるので、小文字または大文字で入力できます。 パラメータが指定されていない場合、デフォルトで「SHA1」値が選択されます。

## 戻り値

パラメーターとして渡された文字列のMD5、SHA-1またはSHA-256 ハッシュ（選択したハッシュのタイプによって異なります）。

## 備考

MD5およびSHA-1型の場合、キーはUTF-8に変換した後、最大64文字（512 ビット）にできます。 SHA-256 タイプの場合、キーはUTF-8に変換した後、最大32文字（256 ビット）にできます。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
