# 一時停止

進行中のワークフローの実行を一時停止します。

```text
Pause ( String workflowId )
```

## パラメーター

**workflowId** ワークフローの識別子または内部名。

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:workflow](s-xtk-workflow.md)

**静的：**

はい
