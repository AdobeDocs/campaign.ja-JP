# PathEdit

フィールドを選択するためのコントロール。

## プロパティ

**backColor – 文字列**&#x200B;背景色（btnshadow、白）。

**border - string** コントロール アウトライン スタイルを変更します（solid、double、inset、outset、none）。

**font-size - integer** フォントサイズを変更します。

**hideCalculated - ブール値**&#x200B;計算フィールドを非表示にします。

**hideMappedAsXml - ブール値**&#x200B;はXML フィールドを非表示にします。

**label – 文字列**&#x200B;関連ラベル。

**ノーラベル – ブール値**&#x200B;関連するラベルを非表示にします。

**noTransaction - ブール値** トランザクションモードを無効にします。

**readOnly - ブール値**&#x200B;は、コントロールを強制的に読み取り専用にします。

**必須 – ブール値** フィールドは必須です。

**useLink11Path - ブール値**&#x200B;は1:1 リンクを示します。

**useTablePath - ブール値** テーブルを表示します。

**useUnboundPath - ブール値** コレクションを表示します。

**xpath – 文字列**&#x200B;編集するフィールド。

**xpathBaseType - xpath**&#x200B;選択したフィールドのタイプを保存するパス。

**xpathDataPolicy - xpath**&#x200B;選択したフィールドのdataPolicy プロパティを保存するためのパス。

**xpathEnum - xpath**&#x200B;選択したフィールドのシステム列挙を保存するパス。

**xpathLabel – 文字列**&#x200B;選択したフィールドのラベルを保存するためのパス。

**xpathSchema – 文字列** スキーマパス。

**xpathSchemaMd5 - xpath** スキーマのMD5を保存するためのパス。

**xpathStartPath - string** startPathのパス（xpathSchemaが定義されている場合にのみ使用）。

**xpathUnbound – 選択したフィールドのバインドされていないプロパティを保存するためのxpath** パス。

**xpathUserEnum - xpath**&#x200B;選択したフィールドの空き列挙を保存するパス。

**xpathType - xpath**&#x200B;選択したフィールドの既定のコントロールを保存するためのパス。

**zoom - ブール値**&#x200B;編集ボタンを表示します。
