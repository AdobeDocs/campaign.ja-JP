# toXMLString

エレメントを文字列に変換します。

```text
toXMLString (format)
```

## パラメーター

**format** XML ドキュメントを書式設定するためのブール値。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
