# get

特定のスキーマとキーに対応するエンティティを読み込んで返します。

```text
get ( [key or content ])
```

## パラメーター

**keyまたはcontent** XML コンテンツのエンティティのキーに対応する文字列で、新しいエンティティを作成または開始します。

## 戻り値

JavaScript オブジェクトの形式でエンティティを返します。

## 備考

getはグローバル関数ではなく、スキーマメソッドです。 呼び出すには、目的のスキーマで接頭辞を付ける必要があります。 次に例を示します。

```javascript
var delivery = NLWS.nmsDelivery.get("12435")
```

このオブジェクトのプロパティとサブプロパティは自由に変更できます。 ドキュメントは、スクリプトが変更された場合に実行が終了すると、自動的にデータベースに保存されます。 作成されておらず、エンティティがまだデータベースにない場合は、エラーであり、スクリプトが中断されます。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
