# fileSize

ファイルのサイズをバイト単位で返します。

```text
fileSize (filename)
```

## パラメーター

**filename** ファイルのフルネーム。

## 戻り値

ファイルのサイズを返します。エラーが発生した場合は–1を返します（例えば、ファイルが見つからなかった場合）。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
