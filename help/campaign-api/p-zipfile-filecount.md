# fileCount

アーカイブ内のファイル数を返します。

```text
fileCount
```

## 備考

このメソッドを使用するには、アーカイブを⌐[open （） &#x200B;](m-zipfile-open.md) メソッドで開いている必要があります。 それ以外の場合は例外が発生します。

## 機能

**クラスのプロパティ：** [ZipFile](c-zipfile.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
