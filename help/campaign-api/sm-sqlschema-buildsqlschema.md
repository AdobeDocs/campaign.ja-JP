# BuildSqlSchema

パラメーターに指定されたテーブルの物理的な構造からスキーマのコードを生成します。

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## パラメーター

データソースの&#x200B;**dataSource** ID

**tableName** テーブル名

## 戻り値

**スキーマ**&#x200B;がスキーマを生成しました
