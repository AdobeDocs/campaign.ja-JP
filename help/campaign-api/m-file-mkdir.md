# mkdir

現在の[File](c-file.md) オブジェクトのパスを持つディレクトリを作成します。

```text
mkdir ()
```

## パラメーター

なし。

## 戻り値

なし。

## 備考

必要に応じて、中間ディレクトリも作成します。 エラーの場合は例外が発生します。

## 機能

**クラスのメソッド：** [&#x200B; ファイル &#x200B;](c-file.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
