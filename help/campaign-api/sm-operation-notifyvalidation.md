# NotifyValidation

キャンペーンにおける承認通知。

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## パラメーター

**deliveryId**&#x200B;配信ID

**target** ターゲティングの検証

**content** コンテンツの承認

**予算**&#x200B;予算承認

**抽出**&#x200B;抽出ファイルの承認

**FCP** プルーフの承認

**サンドボックス** ターゲット見積もりの承認

**edition** コンテンツ編集

**external**&#x200B;外部コンテンツの承認

## 戻り値

なし。
