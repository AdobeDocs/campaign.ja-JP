# GetUsedLanguagesEnum

レポートで使用される言語で列挙を作成します。

```text
XML enum = GetUsedLanguagesEnum ( String designLanguage, String defaultLanguage, XML additionalLanguages )
```

## パラメーター

**designLanguage** デザイン言語

**defaultLanguage**&#x200B;既定の言語

**additionalLanguages**&#x200B;その他の言語

## 戻り値

**enum**&#x200B;使用されている言語を含む列挙
