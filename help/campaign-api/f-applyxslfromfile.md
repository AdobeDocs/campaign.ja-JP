# applyXslFromFile

XSL スタイルシートを使用してXML ドキュメントを変換します。

```text
applyXslFromFile (xslEntity, filename)
```

## パラメーター

**xslEntity** データベースに保存されているXSL スタイルシートの名前。

**filename**&#x200B;変換するXML ファイルの名前。

## 戻り値

変換後の文字列の形式のXML ドキュメント。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
