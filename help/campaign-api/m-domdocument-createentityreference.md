# createEntityReference

新しいエンティティ参照を作成します。

```text
createEntityReference (name)
```

## パラメーター

**name**&#x200B;参照されているエンティティの名前。

## 戻り値

[entity](c-domnode.md)が作成されました。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
