# CreateExportList

買い物かご内のエンティティのエクスポート先リストを作成します。

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## パラメーター

リストの&#x200B;**label** ラベル

リストを作成するフォルダーの&#x200B;**folderId** ID （既定のフォルダーを使用するには0）。

## 戻り値

新しく作成されたリストの&#x200B;**listId** ID

**スキーマ：** [xtk:olapCube](s-xtk-olapcube.md)

はい
