# XMLの使用

多くのJavaScript APIでは、XML型オブジェクトをパラメーターとして取り込むか、返します。 以前のバージョンのAdobe Campaignでは、JavaScript E4X拡張機能を使用して、XML要素を言語で直接操作できるようにしていました。 しかし、このテクノロジーは徐々に放棄されています。

この技術を置き換えるために、XML ドキュメントを操作する新しいオブジェクトが追加されました。 これらは、一部の拡張機能を含むドキュメントオブジェクトモデル（DOM）インターフェイスのサブセットを再開します。 また、XML ドキュメントを簡単に作成するための表記法オブジェクトも使用できます。これは、JXON BadgetFishの規則を簡略化したバージョンです。

## DOM インターフェイス

[DOMDocument](c-domdocument.md) オブジェクトはXML ドキュメントです。 これは、文字列、JXON オブジェクト、またはファイルから直接作成できます。 DOM ドキュメントを作成する例を次に示します。

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

このインタフェースは、W3C仕様の一部と見なされ、様々な顕著な違いがあります。

* 関数getElements\*とchildNodesおよび属性プロパティは、NodeList オブジェクトではなくJavaScript テーブルを返します。これにより、テーブル独自の関数（forEach、map、...）を使用できます。
* 特定のプロパティでは、値が指定されていない場合、nullではなく空の文字列が返されます。

さらに、特定のユーティリティ機能と一部の非標準の拡張機能が追加されています。 例えば、属性を読み取ったり変更したりするには、次のように記述するだけです。

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

代わりに：

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

$name プロパティを持つ属性を割り当てると、文字列、ブール値、日付または数値を取ることができます。値は自動的に文字列に変換されます。

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXONは、JavaScript オブジェクトがXML ドキュメントを簡単に作成するための表記規則です。 この表記法では、すべてのXML ドキュメントを作成することはできません。 例えば、属性と同じ名前の要素を指定することはできず、名前空間は管理されません。 これはAdobe Campaign文書に適しています。 より複雑なニーズに応じて、いつでも従来のDOM関数を使用できます（エレメントごとのエレメントの解析または作成）。 XML オブジェクトは、エレメントと属性に一致するプロパティを持つJavaScript オブジェクトで表されます。 値タイプは、要素と属性のどちらを使用するかを決定します。

* String値が文字列である属性
* ブール値が「true」または「false」の属性
* Number値が10進数表現である属性
* 日付ISO-8601の日付と時刻の表現値を持つ属性
* オブジェクト要素
* 配列エレメントのリスト

エレメントのテキストコンテンツには、$という名前の特殊プロパティが使用されます。例：

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

プロパティに無効なJavaScript IDである特殊文字が含まれている場合は、これらは引用符で囲む必要があります。

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

JXON オブジェクトは、関数が文書またはXML要素を予測する任意の場所で引数で使用できます。 次に例を示します。

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

は次と同等です。

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

XML ドキュメントの操作はDOM オブジェクトによって行われますが、JXON オブジェクトは初期化にのみ使用されるユーティリティです。 リテラル JavaScript構造からXML ドキュメントを作成する方が便利です。特に、ドキュメントに変数部分が含まれている場合に便利です。
