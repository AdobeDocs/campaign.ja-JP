# lookupNamespaceURI

指定されたプレフィックスにリンクされている名前空間のURIを検索しました。

```text
lookupNamespaceURI (prefix)
```

## パラメーター

**接頭辞**&#x200B;接頭辞。

## 戻り値

名前空間のURI、または見つからない場合は空の文字列。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
