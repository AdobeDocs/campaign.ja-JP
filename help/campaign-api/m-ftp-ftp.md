# FTP

FTP コマンドを実行する新しいオブジェクトを作成します。

```text
FTP ()
```

## パラメーター

なし。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [FTP](c-ftp.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
