# fileRes

サーバーまたはデータベースに保存されるファイルリソース

## メソッド

| メソッド | 説明 |
| --- | --- |
| [FilePublishing](sm-fileres-filepublishing.md) | フロントサーバーにパブリックリソースを公開します。 |
| [GetPublicFileResURL](sm-fileres-getpublicfileresurl.md) | フォルダーの URL を取得します |
| [GetServerFileName](sm-fileres-getserverfilename.md) | 必要に応じてアップロードフォルダーにコピーした後で、サーバー上のファイルの名前を返します。 |
| [GetURL](sm-fileres-geturl.md) | ファイルの URL を取得します |
| [PostUpload](sm-fileres-postupload.md) | 定義済みのストレージタイプに応じてアップロード後の処理を実行します。 |
| [PreDownload](sm-fileres-predownload.md) | 定義されたストレージのタイプに応じてリソースのダウンロードを準備します。 |
| [PublishIfNeeded](sm-fileres-publishifneeded.md) | 必要に応じてメディアサーバー上のファイルをコピーします |
| [PublishIfNeededFromId](sm-fileres-publishifneededfromid.md) | 必要に応じてリソース ID を使用してメディアサーバー上のファイルをコピーします |
| [WebPostUpload](sm-fileres-webpostupload.md) | 使用するストレージのタイプに応じて、（web ページから）サーバーにアップロードした後のリソースのストレージを確定します。 コードページとコンテンツタイプを復元します。 |

| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
