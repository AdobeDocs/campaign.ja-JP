# 数

このコントロールを使用すると、数値を入力できます。

![数値制御](assets/number.d018cb51.png)

## プロパティ

**backColor – 文字列**&#x200B;背景色（btnshadow、白）。

**border - string** コントロール中に境界線スタイルを変更します（実線、倍線、インセット、アウトセット、なし）。

**digitCount - integer** コンマの後に表示する数値の数。 デフォルト値は2です。

**font-size - integer** フォントサイズを変更します。

**label – 文字列**&#x200B;関連ラベル。

**ノーラベル – ブール値**&#x200B;関連するラベルを非表示にします。

**readOnly - ブール値**&#x200B;は、コントロールを強制的に読み取り専用にします。

**必須 – ブール値** フィールドは必須です。

**width - integer**&#x200B;表示する文字数。 デフォルト値は18で、000 000 000 000000.00と一致します。
