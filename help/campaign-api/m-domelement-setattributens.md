# setAttributeNS

属性の値を変更するか、新しい属性を作成します。

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## パラメーター

属性名前空間の&#x200B;**namespaceURI** URI。

**qualifiedName**&#x200B;属性の修飾名。

**value**&#x200B;属性テキスト値。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
