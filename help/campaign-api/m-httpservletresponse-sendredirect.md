# sendRedirect

別のURLへの一時的なリダイレクトを返します。

```text
sendRedirect (location)
```

## パラメーター

**location** リダイレクト URL。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [HttpServletResponse](c-httpservletresponse.md)

**次の場所で利用できます：**

* JSSP
* Web アプリ
