# CreateFDASchema

データベースに作業用スキーマを作成

```text
CreateFDASchema ( String server, String account, String password, String port, String options, String schema )
```

## パラメーター

**サーバー** サーバーアドレス

**アカウント** アカウントの名前（またはログイン）

アカウントに関連付けられている&#x200B;**パスワード**

**ポート** サーバーポート

**options**&#x200B;接続オプション

**スキーマ** スキーマ名

## 戻り値

なし。

**スキーマ：** [nms:extAccount](s-nms-extaccount.md)

はい
