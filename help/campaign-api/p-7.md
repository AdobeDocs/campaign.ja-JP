# E4X移行ガイド

JavaScriptでXMLをネイティブにサポートするE4X拡張機能は、Mozillaによって段階的に放棄されます。 Adobe Campaignはこの拡張機能を頻繁に使用していたため、別のソリューションへの移行を準備しています。

このガイドの目的は、既存の設定を移行したり、新しい設定を開発したりする際に、代替ソリューションについて説明することです。

古いシステムと新しいシステムが共存している場合、現在のバージョンのAdobe Campaignは常にE4Xと互換性がありますが、新しいコンフィギュレーションはE4X拡張機能で開発しないでください。

注意：E4Xは、ソースプログラムから直接構築できるJavaScript xmlのタイプを追加します。

```text
var doc = <xml> ... </xml>
```

または文字列から：

```text
var doc = new XML ("<xml>...</xml>")
```

その後、特定のAPIで操作できます。

```text
element.@id element.where
```

## XML タイプ

ネイティブの「xml」タイプはDOM APIに置き換えられます。これらは[DOMDocument](c-domdocument.md)、[DOMElement](c-domelement.md)、[DOMNode](c-domnode.md) タイプです。以下は、最も一般的な操作に相当します。

> **E4X:**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM:**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X:**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM:**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X:**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM:**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> または
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

JAVASCRIPTのXML ドキュメントは置き換える必要があります。 このドキュメントをネイティブ関数またはパラメーター内のXML ドキュメントを渡すSOAP呼び出しに使用する場合は、JXONを直接渡すことができます。 これは自動的にXML ドキュメント（DOMDocument）に変換されます。 そうでない場合は、常にJXON オブジェクトを介して渡すことができますが、[DOMDocument.fromJXON](m-domdocument-fromjxon.md)関数を使用した明示的な変換が必要です。

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

XMLとJXON構文の等価性の例：

> **E4X:**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON:**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

JXON構文について詳しくは、XMLの使用ページを参照してください。

## SOAP Calls

これらのSOAP メソッドは、NLWS オブジェクトプロパティを実行する必要があります。 スキーマのJavaScript IDは、名前空間と名前（大文字で始まる）から作成されます。 例えば、nms:delivery スキーマのJS IDはnmsDeliveryです。

> **古い：**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **新規：**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## SOAP JavaScript メソッド

E4X形式ではなくDOM形式のパラメーターを持つXML ドキュメントを受け取るには、dom=&quot;true&quot;属性をスキーマに追加する必要があります。

## 複数行の文字列

XMLを使用して複数行の文字列を作成する場合、\\n行の末尾を追加するのを忘れて、文字列の連結に置き換える必要があります。

> **古い：**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **新規：**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```

## コンテンツ管理

プレビュー時に、公開テンプレートまたはJavaScript テンプレートからDOM オプションをアクティブ化する必要があります。 JavaScriptの事前処理を使用してXSL変換を行う場合は、DOM オプション（アグリゲータウィンドウ）も有効にする必要があります。
