# DuplicateWithMappingId

ID マッピングを使用してソースドキュメントから新しいドキュメントを複製します

```text
XML mapping = session.DuplicateWithMappingId ( String pk )
```

## パラメーター

ソース文書の&#x200B;**pk** プライマリキー

## 戻り値

**マッピング** ID マッピング

いいえ
