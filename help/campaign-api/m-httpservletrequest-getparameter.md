# getParameter

クエリパラメーターの値を返します。

```text
getParameter (name)
```

## パラメーター

**name** パラメーター名。

## 戻り値

リクエストされたパラメーターの値。

## 機能

**クラスのメソッド：** [HttpServletRequest](c-httpservletrequest.md)

**次の場所で利用できます：**

* JSSP
* Web アプリ
