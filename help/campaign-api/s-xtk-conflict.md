# 対立

> 警告：この関数は、オンプレミス環境で使用できます。

競合するエンティティの一時ストレージ。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | 現在のバージョンを保持します。 |
| [AcceptNew](sm-conflict-acceptnew.md) | 新しいバージョンを現在のバージョンとして受け入れます。 |
| [SetResolved](sm-conflict-setresolved.md) | エンティティに競合がないことを宣言します。 |

## 汎用メソッド

| メソッド | 説明 |
| --- | --- |
| [作成](f-create.md) | 特定のスキーマに対応する新しいエンティティを作成します。 |
| [load](f-load.md) | 特定のスキーマとキーに対応するエンティティを読み込んで返します。 |
| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
