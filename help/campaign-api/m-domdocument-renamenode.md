# renameNode

エレメントまたは属性の名前を変更します。

```text
renameNode (node, namespaceURI, qualifiedName)
```

## パラメーター

**ノード**&#x200B;要素/属性タイプ ノード。

**名前空間URI**&#x200B;新しい名前空間URI。

**qualifiedName**&#x200B;新しい修飾名。

## 戻り値

ノードの名前を変更しました。 これは、指定されたノードでも、古いノードに代わるノードでもかまいません。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
