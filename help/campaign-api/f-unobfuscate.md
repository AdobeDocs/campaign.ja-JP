# 明確化しない

[難読化](f-obfuscate.md)により、以前に難読化された整数を難読化しません。

```text
unobfuscate (value [, version ])
```

## パラメーター

**value**&#x200B;難読化する整数。

**version**&#x200B;適用する難読化されていないバージョン。 デフォルトでは0です。

## 戻り値

以前に[難読化](f-obfuscate.md)によって難読化された整数。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
