# createCDATASection

新しいCDATA タイプノードを作成します。

```text
createCDATASection (data)
```

## パラメーター

CDATA ノードに挿入する&#x200B;**data**&#x200B;文字の文字列。

## 戻り値

[CDATA ノード &#x200B;](c-domcharacterdata.md)が作成されました。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
