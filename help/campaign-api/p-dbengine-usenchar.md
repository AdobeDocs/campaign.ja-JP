# useNChar

Adobe CampaignでNCHAR、NVARCHAR、NCLOB、NTEXT型フィールドを使用する場合はtrueを返します。

```text
useNChar
```

## 機能

**クラスのプロパティ：** [DBEngine](c-dbengine.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
