# setFile

> 警告 :
>
> ファイル API経由のアクセスは、Adobe Campaignの&#x200B;**var**、**sftp**&#x200B;および一時フォルダーに制限されています。

転送モードと受信ファイルを定義します。

```text
setFile (filename)
```

## パラメーター

**filename** ローカルファイルの名前。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [FTP](c-ftp.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
