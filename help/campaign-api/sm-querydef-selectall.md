# SelectAll

選択した部分にすべてのフィールドを追加します。

```text
queryDef.SelectAll ( Boolean duplicate )
```

## パラメーター

**duplicate**&#x200B;複製するかどうかを指定します。この場合、すべてのOwnCopy要素が追加されます。

## 戻り値

なし。
