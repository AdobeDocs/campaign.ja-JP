# 再起動

ワークフローの停止と開始をリンクします。

```text
Restart ( String workflowId )
```

## パラメーター

**workflowId** ワークフローの識別子または内部名。

## 戻り値

なし。

## 機能

**スキーマ：** [xtk:workflow](s-xtk-workflow.md)

**静的：**

はい
