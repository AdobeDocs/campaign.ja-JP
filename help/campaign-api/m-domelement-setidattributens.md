# setIdAttributeNS

指定した属性をID タイプ属性として宣言します。

```text
setIdAttributeNS (namespaceURI, localName)
```

## パラメーター

属性名前空間の&#x200B;**namespaceURI** URI。

**localName**&#x200B;属性名。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMElement](c-domelement.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
