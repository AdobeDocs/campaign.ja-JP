# createProcessingInstruction

新しい処理命令を作成します。

```text
createProcessingInstruction (target, data)
```

## パラメーター

**target**&#x200B;処理命令ターゲット（例：&lt;?php ... ?>）

**data**&#x200B;命令に挿入する文字列。

## 戻り値

[処理命令](c-domnode.md)が作成されました。
