# AcceptNew

新しいバージョンを現在のバージョンとして受け入れます。

```text
AcceptNew ( String conflictId )
```

## パラメーター

**conflictId**&#x200B;競合ID。

## 戻り値

なし。

## 備考

競合がデータベースから削除されます。

## 機能

**スキーマ：** [xtk:conflict](s-xtk-conflict.md)

**静的：**

はい
