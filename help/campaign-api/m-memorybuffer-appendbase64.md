# appendBase64

ベース 64でエンコードされた文字列のデータをバッファの末尾に追加します。

```text
appendBase64 (string)
```

## パラメーター

**文字列** バッファーに追加するベース 64でエンコードされたバイナリ データを表す文字列。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
