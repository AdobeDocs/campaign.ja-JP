# allowEmptyPart

キーのフィールドを空にできる場合はtrueを返します（少なくとも1つのフィールドを入力する必要があります）。

```text
allowEmptyPart
```

## 機能

**クラスのプロパティ：** [SchemaKey](c-schemakey.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
