# 睡眠

指定した時間スクリプトを休止します。

```text
sleep (delay)
```

## パラメーター

**delay**&#x200B;時間（ミリ秒単位）。

## 戻り値

なし。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
