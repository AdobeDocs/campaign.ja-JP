# データ保護：関数のエスケープ

Adobe Campaignには、SQL インジェクション、XSS攻撃など、最も頻繁な攻撃に対する保護を提供する一連の機能が用意されています。

エスケープ機能は、オペレーターの監督下で使用されるものとし、Adobeは、開発中にこれらの機能を不正に使用したり、使用しなかったりする責任を負わない場合があります。

一般的なルールは次のとおりです。

**すべてのパラメーターをエスケープする必要があります。 エスケープに使用される関数は、データの宛先形式によって異なります。**

## エスケープの簡素化

JSSPでは、Adobe Campaignは、生成されたXMLまたはHTML エンティティで使用される変数をエスケープできる&#39;&lt;%=&#39; タグを提供します。 このメソッドはより便利で、NL.XML.escape （）と同等です。 次の例は、タグを使用してパラメーターをエスケープする方法を示しています。

```xml
<li>
<%= strRecipientList %>
</li>
```

## 高度なエスケープ：

Adobe Campaignには、出力先のフォーマットに応じてパラメーターをエスケープできる4つの関数が用意されています。これらのエスケープ関数にアクセスするには、次のファイルにそれぞれ名前を付けます。

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* 生成されたXMLまたはHTML エンティティで使用される変数をエスケープするためのNL.XML.escape （data）。 この関数は、&#39;&lt;%=&#39;構文と同等です。 この関数は、NL.XML パッケージで定義されます。

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape （data）を使用して、SQL クエリで使用できるパラメーターをエスケープします。 この関数は、単純な引用符の間に式を自動的に配置します。 この関数は、NL.SQL パッケージで定義されます。

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString （data）を使用して、XTK式で使用されるパラメーターをエスケープします。 この関数は、NL.XTK パッケージで定義されます。

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape （data）を使用して、クライアントサイドで実行されるjavascriptで使用される変数をエスケープします。 この関数は、NL.JS パッケージで定義されます。

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

警告：Adobe Campaignでは、以降のバージョンでのこれらの機能の耐久性は保証されません。
