# 属性

ノードが要素である場合は属性のリストを含むテーブルを返します。それ以外の場合はnullを返します。

```text
attributes
```

## 備考

このプロパティは、アクセスごとに新しいテーブルを作成します。 したがって、プロパティに何度もアクセスするのではなく、テーブルをローカル変数に保持することをお勧めします。

**クラスのプロパティ：** [DOMNode](c-domnode.md)

はい
