# CreateFromModel

テンプレートから (その内部名から) 配信を作成。

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## パラメーター

**scenarioName**&#x200B;配信テンプレートの内部名

テンプレートに追加する&#x200B;**content** XML コンテンツ

## 戻り値

**delivery**&#x200B;作成された配信ドキュメントを返します

**スキーマ：** [nms:delivery](s-nms-delivery.md)

はい
