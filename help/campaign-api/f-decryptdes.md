# decryptDES

> 警告 :
>
> この関数は廃止されました。[decryptString （） &#x200B;](f-decryptstring.md)を使用してください。

DES アルゴリズムで文字列の暗号化を解除します。

```text
decryptDES (key, value [, cipher mode ] [, initialization vector ])
```

## パラメーター

**key** キーは16進数で表されます。 キーは64 ビット長または16進数の16文字である必要があります。

**value** ベース 64で表される、暗号化するデータ。

**暗号モード** ブロックをコーディングするためのメソッドです。 文字の文字列。 つまり、「CBC」、「ECB」、「EDE」です。 デフォルトでは「CBC」です。

**初期化ベクトル** 16進数文字列の形式の初期化ベクトル。 正確に8 オクテット、つまり16文字です。 デフォルトでは空の文字列。

## 戻り値

クリアテキストの文字列。

## 備考

* DES鍵は56の有用なビットと8のビットを持ち、パリティのために使われる。
* データは、Windows-1252 コードページの8 ビット文字列として暗号化されません。
* 暗号化されたデータの長さは、64 ビットの倍数である必要があります。
