# HtmlToText

HTML コンテンツをプレーンテキストに変換

```text
String textContent = HtmlToText ( String htmlContent )
```

## パラメーター

コンバージョンする&#x200B;**htmlContent** HTML コンテンツ

## 戻り値

**textContent**&#x200B;は変換されたテキストを返します
