# PushTrackingInfo

リモートトラッキングサーバーで配信に関するすべての情報をアップロードすることを許可します。

```text
PushTrackingInfo ( String instance, String dbId, String jobId, XML document )
```

## パラメーター

**インスタンス** インスタンス名

配信を実行する顧客の&#x200B;**dbId** データベース ID

**jobId**&#x200B;配信ID。

この配信のトラッキング情報を含む&#x200B;**ドキュメント** ドキュメント

## 戻り値

なし。
