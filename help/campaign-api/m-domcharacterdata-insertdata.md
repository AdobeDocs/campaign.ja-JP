# insertData

テキストを特定の位置に挿入します。

```text
insertData (offset, arg)
```

## パラメーター

**offset**&#x200B;挿入位置（最初の文字は0）。

挿入する&#x200B;**arg**&#x200B;文字列。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [DOMCharacterData](c-domcharacterdata.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
