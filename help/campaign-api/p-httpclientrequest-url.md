# URL

リモートサーバーのアドレス。

```text
url
```

## 備考

読み取り/書き込みモードのプロパティ。 例：

```javascript
var http = new HttpClientRequest()
http.url = "http://www.adobe.net"
```

## 機能

**クラスのプロパティ：** [HttpClientRequest](c-httpclientrequest.md)

**読み取り専用：**

いいえ

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
