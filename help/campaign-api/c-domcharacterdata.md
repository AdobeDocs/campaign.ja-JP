# DOMCharacterData （クラス）

テキストのみを含むノード。 テキストタイプノードまたはコメントを指定できます。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | テキストの一部を抽出します。 |
| [appendData](m-domcharacterdata-appenddata.md) | テキストに文字列を追加します。 |
| [insertData](m-domcharacterdata-insertdata.md) | テキストを特定の位置に挿入します。 |
| [deleteData](m-domcharacterdata-deletedata.md) | テキストの一部を削除します。 |
| [replaceData](m-domcharacterdata-replacedata.md) | テキストの一部を置き換えます。 |

## プロパティ

| プロパティ | 説明 |
| --- | --- |
| [ データ ](p-domcharacterdata-data.md) | ノードのテキスト値。 |
| [length](p-domcharacterdata-length.md) | ノード内の文字の数。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
