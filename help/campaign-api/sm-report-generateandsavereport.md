# GenerateAndSaveReport

サーバーからレポートを生成してデータベースに保存します

```text
XML result = GenerateAndSaveReport ( String reportName, XML context )
```

## パラメーター

**reportName** レポートの内部名

**context** レポート設定

## 戻り値

**結果**&#x200B;一意のIDとレコード日

**スキーマ：** [xtk:report](s-xtk-report.md)
