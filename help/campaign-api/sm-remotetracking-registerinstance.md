# RegisterInstance

トラッキングインスタンスの承認に使用されます

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## パラメーター

**instanceName**&#x200B;承認するインスタンスの名前

配信を実行する顧客の&#x200B;**dbId** データベース ID

**lang** インスタンス言語

## 戻り値

なし。

## 機能

**スキーマ：** [nms:remoteTracking](s-nms-remotetracking.md)

**静的：**

はい
