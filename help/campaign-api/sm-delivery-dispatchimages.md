# DispatchImages

ミッドソーシングサーバーに画像を送信するようアプリケーションサーバーに指示します。

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## パラメーター

**images** ミッドソーシングサーバーにアップロードする画像のリスト。

配信ルーターの&#x200B;**providerId**&#x200B;識別子。

**providerName**&#x200B;配信ルーターの名前。

## 戻り値

なし。

## 機能

**スキーマ：** [nms:delivery](s-nms-delivery.md)

**静的：**

はい
