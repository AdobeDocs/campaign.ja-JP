# BuildOutputNavTree

データベースにあるナビゲーションツリーの定義とパラメーターで指定した定義とを結合します。

```text
XML navtree = BuildOutputNavTree ( XML navtreeSource, Boolean save )
```

## パラメーター

**navtreeSource** Source ナビゲーション ツリー

**save**&#x200B;結果を保存

## 戻り値

**navtree**&#x200B;結合の結果
