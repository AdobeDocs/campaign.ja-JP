# ロード

ファイルの内容をバッファに読み込みます。

```text
load (filename)
```

## パラメーター

**filename** ロードするファイルの名前。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
