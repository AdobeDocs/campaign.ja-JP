# createElement

新しいエレメントを作成します。

```text
createElement (tagName)
```

## パラメーター

**tagName**&#x200B;作成する要素の名前。

## 戻り値

[要素](c-domelement.md)が作成されました。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
