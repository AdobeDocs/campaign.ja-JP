# BuildSqlSchemaDiff

実際のデータベース構造とその論理的説明の違いを説明するドキュメントを生成します。

```text
XML sqlSchemaDiff = BuildSqlSchemaDiff ( XML sqlDiffParam, XML package )
```

## パラメーター

**sqlDiffParam**&#x200B;拡張パラメーター

**パッケージ**&#x200B;初期パッケージ

## 戻り値

**sqlSchemaDiff**&#x200B;が生成されました
