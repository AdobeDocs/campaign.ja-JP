# fileIsRelative

ファイル名が相対名かどうかを指定します。

```text
fileIsRelative (fileName)
```

## パラメーター

**fileName** ファイル名。

## 戻り値

ファイル名のTrueは相対的です。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
