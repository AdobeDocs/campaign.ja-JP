# SysEnum

このコントロールでは、システム列挙から値を選択できます。

![SysEnum コントロール &#x200B;](assets/sysenum.1eccf324.png)

## プロパティ

**backColor – 文字列**&#x200B;背景色（btnshadow、白）。

**border - string** コントロール アウトライン スタイルを変更します（solid、double、inset、outset、none）。

**defaultIfInvalid – 値が無効な場合に使用する値**&#x200B;です。

**enum - string**&#x200B;列挙を使用します。

**font-size - integer** フォントサイズを変更します。

**label – 文字列**&#x200B;関連ラベル。

**noInvalidErr - ブール値**&#x200B;値が無効な場合はエラーは表示されません。

**ノーラベル – ブール値**&#x200B;関連するラベルを非表示にします。

**readOnly - ブール値**&#x200B;は、コントロールを強制的に読み取り専用にします。

**必須 – ブール値** フィールドは必須です。

**serialize - ブール値**&#x200B;最後に選択した値を保存します。

**useDesc - ブール値** ラベルではなく説明を表示します。

**xpathEnum - xpath**&#x200B;列挙の列挙プロパティではなく、このXPathで参照されている値を使用します。
