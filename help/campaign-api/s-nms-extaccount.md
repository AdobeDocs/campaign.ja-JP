# extAccount

外部アカウントの定義（電子メール、SMSなど） モジュールによって使用される

## メソッド

| メソッド | 説明 |
| --- | --- |
| [CreateFDASchema](sm-extaccount-createfdaschema.md) | データベースに作業用スキーマを作成 |
| [DeclareTableSpaces](sm-extaccount-declaretablespaces.md) | 外部アカウント経由でアクセス可能なリモートデータベースの特定の表領域を使用するために必要なオプションを Adobe Campaign データベースで宣言します。 |
| [DeploySQLFunctions](sm-extaccount-deploysqlfunctions.md) | Adobe Campaign Federated Data Access に必要な機能をリモート RDBMS サーバーにデプロイします |
| [TestAccount](sm-extaccount-testaccount.md) | 接続テストを実行 |

## 汎用メソッド

| メソッド | 説明 |

| [load](f-load.md) | 特定のスキーマとキーに対応するエンティティを読み込んで返します。 |
| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
