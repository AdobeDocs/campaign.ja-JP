# LoadIfExists

存在する場合にエンティティを読み込み

```text
Boolean Exists = session.LoadIfExists ( String pk )
```

## パラメーター

**pk** プライマリキー

## 戻り値

**Exists** エンティティが存在するかどうかを表示します

**スキーマ：** [xtk:session](s-xtk-session.md)

**静的：**

いいえ

**定数：**

いいえ

**キーのみ：**

いいえ
