# getElementById

指定されたIDを持つ要素を返します。

```text
getElementById (elementId)
```

## パラメーター

**elementId**&#x200B;検索された要素の識別子。 大文字と小文字を区別する文字列。

## 戻り値

ドキュメントに特定のIDを持つ要素が含まれていない場合は、要素またはnull。

## 機能

**クラスのメソッド：** [DOMDocument](c-domdocument.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
