# sha256

MemoryBuffer コンテンツのSHA-2 256 ビット署名を計算します。

```text
sha256 ()
```

## パラメーター

なし。

## 戻り値

SHA-2 256 ビット署名の16進数表現である文字列。

## 機能

**クラスのメソッド：** [MemoryBuffer](c-memorybuffer.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
