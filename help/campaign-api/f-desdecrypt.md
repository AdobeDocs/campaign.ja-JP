# DESdecrypt

> 警告 :
>
> この関数は廃止されました。[decryptString （） ](f-decryptstring.md)を使用してください。

DES アルゴリズムを使用してデータを読み解きます。

```text
DESdecrypt (value [, key ] [, cipher mode ] [, initialization vector ])
```

## パラメーター

**value** デジタル化するデータをベース 64で表します。

**key** キーは16進数で表されます。 キーの長さは64 ビット、つまり16進数の文字である必要があります。 デフォルトでは、データベースの識別子が使用されます。

**暗号モード** ブロックエンコーディングメソッド。 1文字の文字列。 つまり、「CBC」、「ECB」、「EDE」です。 デフォルトでは「CBC」です。

**初期化ベクトル** 16進数文字列の形式の初期化ベクトル。 正確に8 オクテット、つまり16文字です。 デフォルトでは空の文字列。

## 戻り値

暗号化されていない文字列。

## 備考

* DES鍵は56の有用なビットと8のビットを持ち、パリティのために使われる。
* データは、Windows-1252 コードページの8 ビット文字列として暗号化されません。
* 暗号化されたデータの長さは、64 ビットの倍数である必要があります。
