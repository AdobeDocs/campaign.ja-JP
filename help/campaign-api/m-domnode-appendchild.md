# appendChild

サブフォルダーのリストの最後にノードを挿入します。

```text
appendChild (newChild)
```

## パラメーター

挿入する&#x200B;**newChild** ノード。

## 戻り値

挿入されたノード。

## 機能

**クラスのメソッド：** [DOMNode](c-domnode.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
