# 日付の使用

この章では、サーバー上で実行されるJavaScript プログラム（ワークフロー、JSSPなど）の日付を操作するために使用する関数について説明します。

## 日付とタイムゾーン

JavaScriptでは、日付はUTCで保存されます。 つまり、日付の構築や内部表示またはストレージ用のテキスト文字列への変換のタイムゾーンについて心配するだけで済みます。日付変換には、次の2つの機能カテゴリがあります。

* JavaScript ライブラリの関数（date.toString （）, date.toLocaleString （）, date.getHours （）, ...）,
* Adobe Campaign プラットフォームの関数（[formatDate （date, format） ](f-formatdate.md)）。

慣習により、最初はマシンのタイムゾーンを使用し、最後はコンテキストに応じてタイムゾーンを使用します。通常は現在のオペレーターのタイムゾーンですが、この動作は書き出しやワークフローなどのために変更できます。

## 現在の日付を取得

JavaScriptで現在の日付を取得するには、次の2つの方法があります。

* new Date （）は、現在の日付で初期化された新しいDate オブジェクトを作成します。 日付は、スクリプトが実行されるマシンの時刻と一致します。
* [getCurrentDate （） ](f-getcurrentdate.md)は、データベースサーバーの時刻に基づいて現在の日付を返します。

[getCurrentDate （） ](f-getcurrentdate.md)関数は、最初のソリューションよりも好ましく、特に日付をデータベースの他の日付と比較したり、データベースに書き込んだりする場合に適しています。 この方法は、アプリケーションサーバーとデータベースサーバーの間の時間差に関連する不一致のリスクを低減します（最大数分）

## 日付の表示

表示目的で日付を文字列に変換するには、[formatDate](f-formatdate.md)関数を使用します。

## XML ドキュメントからの日付の変換

Adobe Campaign データベースから取得したXML ドキュメントに保存された日付はテキスト形式です。[parseTimeStamp](f-parsetimestamp.md)関数を使用して変換できます。 これは通常、[ExecuteQuery](sm-querydef-executequery.md) メソッドによって返されるXML ドキュメントに関するものです。 例：

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## XML ドキュメントへの日付の挿入

XML属性に日付を書き込む、文書を保存する（[Write](sm-session-write.md) メソッド）、またはクエリの式にリテラル日付を挿入する場合、日付はISO8601形式に変換する必要があります。 xtk:shared/nl.js関数ライブラリには、日付をこの形式に変換する方法（NL.XTK.formatDateTime （date） メソッド）があります。 ライブラリは、loadLibrary関数を使用してロードできます。

```javascript
loadLibrary("xtk:shared/nl.js")
```

動的なJavaScript page （JSSP）の場合は、page ディレクティブを使用します。

```xml
<%@ page import="xtk:shared/nl.js" %>
```

警告：すべてのスクリプトにloadLibraryを使用することはできません。 例えば、メールのパーソナライゼーションスクリプトでJavaScript関数のライブラリを変更することはできません。 例：次の例は、リテラル日付を使用したクエリの構築を示しています。

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
