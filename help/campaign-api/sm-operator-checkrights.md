# CheckRights

指定されたグループに対する権限が現在のオペレーターに割り当てられているかどうかを確認します

```text
CheckRights ( String groupList )
```

## パラメーター

**groupList** グループ IDのリスト （コンマ区切り）

## 戻り値

なし。
