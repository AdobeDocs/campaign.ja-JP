# 完了

非同期クエリが終了したときに呼び出す関数。

```text
complete
```

## 備考

関数は4つの引数を受け入れる必要があります。

* サービス
* 成果
* コンテキスト：これは、[start](m-soapservice-start.md)関数に渡されるパラメーターです
* ステータス

ステータスには、次の値を指定できます。

* 「成功」とは、結果が受信されたことを意味します。
* 「エラー」とは、通信が中断されたこと、応答が適切に構造化されていないこと、またはHTTP エラーが発生したことを意味します。
* SOAP エラーが返された場合、「fault」。 この場合、結果にはエラーを記述するオブジェクトが含まれます。
* 「タイムアウト」とは、接続が確立できなかったか、設定された期限内に応答が受信されなかったことを意味します。

結果が「成功」の場合、結果は返されるパラメーターの数によって異なります。

* クエリが値を返さない場合は無効になります
* クエリが1つのパラメーターを返す場合の値
* クエリが複数のパラメーターを返す場合のテーブル

ステータスが「fault」の場合、結果は次のプロパティを含むオブジェクトになります。

* message: エラー説明メッセージ。
* オブジェクト：エラーの詳細を含むXML オブジェクト。

例：

```javascript
http.complete = function(result, context, status)
{
  if( status == "success" )
    logInfo("Response code = " + result[0])
}
```
