# canRead

ファイルが読み取り可能な場合はtrueを返します。

```text
canRead
```

## 機能

**クラスのプロパティ：** [ ファイル ](c-file.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
