# GetDeliveryCustomizationAsModel

選択したパーソナライゼーションフィールドパラメーターをコピーします。

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## パラメーター

選択したテンプレート IDを含む&#x200B;**selection**&#x200B;要素

既存のパーソナライゼーションを含む&#x200B;**parentIn**&#x200B;要素

## 戻り値

**parentOut**&#x200B;新しいテンプレートが追加された要素を返します
