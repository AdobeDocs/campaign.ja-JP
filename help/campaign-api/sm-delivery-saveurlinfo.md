# SaveUrlInfo

この配信の URL を URL テンプレートとして保存します。

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## パラメーター

**insUrlList**&#x200B;新しいURLのリスト （URL テンプレートに関連付けられていません）

**updUrlList**&#x200B;更新するURL テンプレートのリスト

## 戻り値

なし。

**スキーマ：** [nms:delivery](s-nms-delivery.md)

**静的：**

はい
