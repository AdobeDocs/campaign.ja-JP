# rmdir

ディレクトリを削除します（カスケードではありません）。

```text
rmdir ()
```

## パラメーター

なし。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [&#x200B; ファイル &#x200B;](c-file.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
