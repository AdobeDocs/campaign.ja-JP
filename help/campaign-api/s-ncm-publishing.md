# 公開

コンテンツを公開するために使用するテンプレート

## メソッド

| メソッド | 説明 |
| --- | --- |
| [CheckJavaScript](sm-publishing-checkjavascript.md) | JavaScript 変換の有効性を確認 |
| [CheckXSLT](sm-publishing-checkxslt.md) | XSLT ベースの変換をチェック |
| [GenerateForDelivery](sm-publishing-generatefordelivery.md) | 配信のコンテンツを生成します |
| [GenerateFromId](sm-publishing-generatefromid.md) | フォルダー内の識別子で参照されたコンテンツを生成して公開します |
| [GenerateFromSel](sm-publishing-generatefromsel.md) | 選択項目からコンテンツのリストを生成して公開 |
| [LoadContent](sm-publishing-loadcontent.md) | 識別子のリストからコンテンツを読み込み |
| [変形](sm-publishing-transform.md) | コンテンツからの公開時変換 |
| [TransformFromId](sm-publishing-transformfromid.md) | コンテンツ ID からの公開時変換 |
| [TransformJavaScript](sm-publishing-transformjavascript.md) | JavaScript ベースの公開時変換 |
| [TransformJavaScriptDOM](sm-publishing-transformjavascriptdom.md) | JavaScript ベースの公開時変換 |
| [TransformXSLT](sm-publishing-transformxslt.md) | XSLT ベースの公開時変換 |

## 汎用メソッド

| メソッド | 説明 |
| --- | --- |
| [作成](f-create.md) | 特定のスキーマに対応する新しいエンティティを作成します。 |
| [load](f-load.md) | 特定のスキーマとキーに対応するエンティティを読み込んで返します。 |
| [保存](m-entity-save.md) | データベースにエンティティを保存します。 |
