# isFile

ファイルが存在し、ファイルである場合はtrueを返します。

```text
isFile
```

## 機能

**クラスのプロパティ：** [ ファイル ](c-file.md)

**読み取り専用：**

はい

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
