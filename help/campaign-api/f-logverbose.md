# logVerbose

ワークフローインスタンスのログに情報メッセージを追加します。 このメッセージは「詳細」モードでのみ表示されます。

```text
logVerbose (message)
```

## パラメーター

**message** ログに追加するメッセージ。

## 戻り値

なし。

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* 配信メッセージ
* タイポロジルール
* 読み込み
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
