# ZipFile （クラス）

Zip ファイルを操作します。

## メソッド

| メソッド | 説明 |
| --- | --- |
| [ZipFile](m-zipfile-zipfile.md) | ファイルに関連付けられた新しいZip オブジェクトを作成します。 |
| [破棄](m-zipfile-dispose.md) | オブジェクトで使用されるリソースを解放します。 |
| [開く](m-zipfile-open.md) | 既存のアーカイブを読み込みます。 |
| [getEntry](m-zipfile-getentry.md) | アーカイブからファイルを抽出します。 |
| [setEntry](m-zipfile-setentry.md) | アーカイブ内のファイルを追加または更新します。 |
| [保存](m-zipfile-save.md) | アーカイブを保存します。 |

## プロパティ

| プロパティ | 説明 |
| --- | --- |
| [fileCount](p-zipfile-filecount.md) | アーカイブ内のファイル数を返します。 |

## 機能

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
