# 非連携

オブジェクトのHTTP接続を「キープアライブ」モードで閉じます。

```text
disconnect ()
```

## パラメーター

なし。

## 戻り値

なし。

## 機能

**クラスのメソッド：** [HttpClientRequest](c-httpclientrequest.md)

**次の場所で利用できます：**

* コンテンツ管理
* 配信プロパティ
* タイポロジルール
* JSSP
* SOAP メソッド
* Web アプリ
* ワークフロー
